DIRECT ANSWER

Deepgram Nova-3 vs ElevenLabs Scribe v2: which should you choose?

Deepgram Nova-3 and ElevenLabs Scribe v2 are speech-to-text (STT) systems, not text generation or video creation models. For prerecorded transcription, both are plausible choices; choose based on measured accuracy for your recordings, language/dialect coverage, diarization, keyterms, pricing and security needs. Deepgram also offers Nova-3 streaming. For comparable ElevenLabs live audio, evaluate the separate Scribe v2 Realtime model, not the batch product compared here.

Cost snapshot (October 21, 2026): Deepgram Nova-3 monolingual prerecorded is listed at $0.0043/min ($0.258/audio hour); Nova-3 multilingual prerecorded at $0.0052/min ($0.312/hour); ElevenLabs Scribe v2 at $0.22/audio hour before additional paid features. The cheapest base rate is not an accuracy or total-value winner. Deepgram's pricing · ElevenLabs' API pricing.

Editorial verdict

There is no independently measured overall accuracy winner in this article. We distinguish provider specifications from SXF's reproducible offline evaluation demonstration, and we do not present synthetic model transcripts as real vendor results.

TRANSCRIPTION FIELD GUIDE

Speaker diarization and word timestamps: what matters for meeting transcripts

Speaker diarization attributes spoken segments to different speakers; it is not the same as identifying a person's real-world identity. Word timestamps align text with audio; neither guarantees perfect assignment when multiple people overlap. Both products offer transcript metadata useful for subtitling, meeting notes and QA, but the correct choice depends on testing the same recordings.

Deepgram detail worth knowing: the documented diarize_model API selects a diarizer. Batch supports v1 or v2, and the then-current v2 is not supported in streaming; diarize=true is deprecated and routes to v1. Pin a specific version in reproducible production evaluations. The provider explicitly updated diarization APIs in 2026. Official diarization docs.

ElevenLabs detail: Scribe v2 lists word-level timestamps and speaker diarization for up to 32 speakers. That is a stated capability, not evidence your 20-person meeting will be perfectly diarized. Speaker overlap, changing microphones and dialects need direct testing. Scribe documentation.

API integration: reproducible requests for the same prerecorded WAV file

Both vendors expose HTTP interfaces; their request formats differ. Deepgram accepts binary audio with transcription parameters in the query string. ElevenLabs accepts multipart form data with model_id=scribe_v2. Examples are intentionally minimal and use environment variables for secrets. Check current API documentation and audio size limitations before production.

BASH — DEEPGRAM · REPRODUCIBLE EXAMPLE
# 1) Export DEEPGRAM_API_KEY in your shell.
# 2) Use the same consented WAV file for both batch services.
curl --fail-with-body -X POST \
  'https://api.deepgram.com/v1/listen?model=nova-3&punctuate=true&diarize_model=v2' \
  -H "Authorization: Token ${DEEPGRAM_API_KEY}" \
  -H 'Content-Type: audio/wav' \
  --data-binary @sample.wav
BASH — ELEVENLABS · REPRODUCIBLE EXAMPLE
# Export ELEVENLABS_API_KEY in your shell.
# Scribe v2 (batch), not Scribe v2 Realtime.
curl --fail-with-body -X POST 'https://api.elevenlabs.io/v1/speech-to-text' \
  -H "xi-api-key: ${ELEVENLABS_API_KEY}" \
  -F 'model_id=scribe_v2' \
  -F 'diarize=true' \
  -F 'file=@sample.wav;type=audio/wav'

These are reference commands, not executed provider calls by SXF; no API keys or paid usage were available for this publication. Inspect the actual output structure and timestamps; normalizing two different JSON schemas into identical text can hide speaker and timing information. The pairs are editorially constructed examples (invoice wording, spoken numbers, brand spelling, word order and a French sentence). They are not outputs from Deepgram or ElevenLabs. TRANSCRIPTION FIELD GUIDE

How to benchmark Nova-3 and Scribe v2 fairly on your own audio

  1. Consent and retention: obtain rights to use the audio and identify sensitive content. Avoid publishing private call recordings or transcripts.
  2. Corpus: sample at least multiple dialects, speakers, microphones, call/noise conditions, names/numbers, code-switch and silence; choose a justified size for your risk.
  3. References: create double-reviewed human transcripts with a published standard for punctuation, case, numbers, fillers and non-speech events.
  4. Same files: call the supported batch models using the same unmodified audio files. Pin request parameters and recording metadata.
  5. Run variants: test without keyterms first, then with the same business vocabulary where provider constraints allow; record feature charges.
  6. Score: report micro-averaged WER/CER, domain keyterm error rate, timestamp tolerances, diarization error rate and per-language/per-noise strata.
  7. Operational data: measure actual completed-job time, concurrency, failures, total billable audio time and human correction minutes per audio hour.
  8. Publish limitations: report the exact files (or secure dataset manifest), corpus size, language distribution, evaluation scripts, provider/model versions and uncertainty; don't invent a global winner.

TRANSCRIPTION FIELD GUIDE

Data security, PII detection, retention and enterprise readiness

Audio recordings can reveal names, account information, health details and other personal information. Check the provider's current contractual processing terms, retention and deletion controls, regional processing, logging and access management before uploading real customer recordings. The availability of a redaction or entity-detection feature does not guarantee that every sensitive field will be removed.

ElevenLabs documents optional timestamped entity detection; Deepgram offers separate redaction capabilities in supported speech workflows. Each requires its own documented evaluation and possibly billing. For regulated health-related work, confirm the precise STT product/service eligibility and contract rather than assuming a BAA covering a separate voice-agent product covers every API.

TRANSCRIPTION FIELD GUIDE

Seven mistakes that invalidate STT model comparisons

  1. Comparing Scribe v2 batch against Nova-3 streaming but drawing conclusions about a common model architecture.
  2. Using token-based price and context-window comparisons for audio-minute-metered speech models.
  3. Using a provider's marketing WER against another provider's unrelated test dataset.
  4. Failing to control language, audio quality, keyterms, diarization version and normalization.
  5. Calling an entity detection feature a guarantee of privacy or error-free redaction.
  6. Publishing made-up API transcripts as if they came from live paid model tests.
  7. Optimizing solely for per-hour processing cost without including correction labor and security constraints.

Deepgram Nova-3 vs ElevenLabs Scribe v2: frequently asked questions

Which is cheaper for prerecorded audio, Deepgram Nova-3 or ElevenLabs Scribe v2?

At the published baseline checked October 21, 2026, Deepgram Nova-3 monolingual batch lists $0.0043 per minute ($0.258 per audio hour), multilingual lists $0.0052/min ($0.312/hour), and ElevenLabs Scribe v2 lists $0.22/audio hour before optional add-ons and plan effects. A lower published rate does not prove lower total cost per accurate transcript.

Is Deepgram Nova-3 more accurate than Scribe v2?

A reliable winner cannot be established from incompatible provider-reported benchmark claims. Evaluate both on the same consented audio, dialects, named entities, audio quality and reference transcripts, using WER/CER and human review.

Does Scribe v2 support real-time streaming?

The compared Scribe v2 is the batch/file transcription model. ElevenLabs markets a separate Scribe v2 Realtime product. Deepgram Nova-3 supports both prerecorded and streaming use cases.

How many languages do Nova-3 and Scribe v2 support?

ElevenLabs documents Scribe v2 coverage for 90+ languages. Deepgram Nova-3 documents multiple language-specific configurations and a 10-language multilingual mode; consult the current language list for your exact desired model and region.

Can both models identify speakers?

Both offer speaker diarization workflows. Deepgram's current API supports versioned diarizers and distinct batch versus streaming availability. ElevenLabs Scribe v2 publishes diarization up to 32 speakers; measure DER and error propagation in your own audio.

What is the difference between keyterm prompting?

Deepgram Nova-3 accepts keyterm hints under documented total token limits; Scribe v2 batch documents up to 1,000 keyterms of up to 50 characters and charges extra for keyterm prompting. These are not equivalent guaranteed-vocabulary features.

Should I compare their prices per token?

No. These are speech-to-text models billed principally by audio time, so compare the same prerecorded duration and eligible features, including multilingual mode and optional add-ons.

What is the best speech-to-text API for call centers?

First decide batch versus live streaming, speaker separation, accents, specialist vocabulary, redaction, contractual security and total cost per accepted transcript. A service must pass tests on your consented call recordings.

Does SXF have a head-to-head benchmark showing which model wins?

No. SXF publishes a reproducible local transcription-scoring demonstration and an evaluation protocol, not fabricated Deepgram or ElevenLabs API outputs. Neither vendor was tested with paid audio API calls in this comparison.

How can I test the accuracy of speech transcription models?

Build a consented reference corpus with dialects, noisy calls, names and numbers; run both batch models under recorded configurations; compare normalized WER/CER, keyterm error rates, speaker attribution, processing duration and cost, then inspect human-reviewed samples.
