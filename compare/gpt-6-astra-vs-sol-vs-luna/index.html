QUICK ANSWERS

What is the difference between GPT-6 Astra, Sol and Luna?

OpenAI positions Astra as its most capable model for the hardest end-to-end work, Sol for complex coding and agentic workflows, and Luna as its most efficient option for focused high-volume tasks.

Do GPT-6 Astra, Sol and Luna have the same context window?

Yes. OpenAI lists a 1,050,000-token context window and a 128,000-token maximum output for all three models.

Which GPT-6 model is cheapest?

GPT-6 Luna has the lowest listed token prices: $0.10 per 1M input tokens, $0.01 cached input and $0.50 output at the listed short-context rates.

When does GPT-6 long-context pricing apply?

OpenAI states that prompts above 272K input tokens use higher rates for the full request: 2x input and cache rates and 1.5x output rates.
