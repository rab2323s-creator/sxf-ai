AI Agent Lab: 9 Hands-On Tests, 3 Products

A controlled exploratory comparison of ChatGPT Work, Claude Cowork and Manus Lite. Each tool was given the same tasks and initial instructions, once per task.

Test protocol

Test 01 — CSV analysis: identify overdue, blocked, and due-today tasks in a six-row synthetic CSV as of November 3, 2026. Answer key: overdue T102 and T104; blocked T104; due today T106.

Test 02 — Excel reconciliation: apply the latest valid timestamped changes to ten baseline tasks, ignoring post-cutoff and unknown updates, then assess task status and owner capacity at November 3, 2026, 12:00 UTC. Answer key: overdue T201, T205 and T209; blocked T204 and T205; due today T206 and T210; 41 hours of remaining work versus 34 hours available, a 7-hour shortfall.

Test 03 — Autonomous web research: compare official documentation for ChatGPT Work, Claude Cowork and Manus. Produce a research report and source evidence CSV, distinguishing verified claims from uncertainty. We checked some cited sources but did not exhaustively validate the reports.

What the tests do not show

There was only one run per scenario and product. The tests do not establish repeatability, comparative factual accuracy, speed, cost, resilience, security, permissions safety, or production readiness. The Manus run used Lite. Neither Zapier Agents nor Devin was part of the hands-on trial. A generated web report is not the same thing as independently verified research accuracy.
