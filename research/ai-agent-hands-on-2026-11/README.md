## Study notes and limitations

- One attempt per test/product: these data do not establish repeated-run reliability.
- No standardized execution times, prices, credits, token costs, operational safety, or failure recovery were measured.
- Reports were not exhaustively independently fact-checked. Research citation counts alone are not measures of correctness.
- Manus Lite was the tested edition. Zapier Agents and Devin were not part of these nine experiments.
- Some agent-produced text reports were recovered from the original ZIP packages; the published GitHub text copies may differ in newline encoding from original byte streams. Do not equate GitHub text SHA with the original ZIP file's hash.
