# SXF AI Agent Lab — November 3, 2026

Original exploratory research comparing ChatGPT Work, Claude Cowork, and Manus Lite: three standardized single-prompt scenarios per product (nine total). See the accompanying study page and downloadable evidence artifacts for the method, results, and limitations.

The structured-data tests matched their reference answer keys. Each product produced a web research report. One run per scenario does not establish repeatability, comparative superiority, security, speed or production-readiness. The research claims were not exhaustively verified. Zapier Agents and Devin were not tested in this series.

Related SXF resources: [25-test evaluation checklist](https://sxf.si/guides/ai-agent-evaluation-checklist/) and [AI agent reliability research](https://sxf.si/research/ai-agent-reliability/).
