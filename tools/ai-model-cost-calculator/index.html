HOW IT WORKS

One workload. Comparable token economics.

The calculator keeps the assumptions visible so GPT, Claude and Gemini estimates use the same token counts, request volume and billing date.

01

Choose a model

Select a cataloged model from OpenAI, Anthropic or Google. The calculator loads its verified Standard API pricing periods and limits.

02

Enter token usage

Separate uncached input, cached input and output tokens. Cached input is not blended into ordinary input pricing.

03

Scale the request

Use requests per day to see per-request, daily, 30-day and 1,000-request estimates from the same workload.

04

Apply pricing rules

Dated pricing periods and stored long-context multipliers are applied automatically when the catalog defines them.

WHAT IS INCLUDED

Token cost, without hidden assumptions.

This calculator is intentionally scoped to direct token economics so cross-provider estimates remain understandable.

AI MODEL COST FAQ

Common calculator questions.

Use the official provider billing documentation as the final authority before production procurement or budgeting.

How does the AI model cost calculator work?

Choose a model and enter uncached input, cached input and output tokens. SXF selects the stored Standard API pricing period for the billing date, applies any stored long-context rule, and calculates direct token cost per request, per day and for 30 days.

Can I compare GPT, Claude and Gemini API costs?

Yes. Choose a comparison model and both estimates use exactly the same workload and billing date. The comparison is a token-cost comparison only; it does not rank model quality, latency or suitability.

Does the calculator include cached input pricing?

Yes. Cached input has its own field and is priced separately using the cached-input rate stored for the selected model and pricing period.

What does the 30-day estimate mean?

It multiplies the calculated per-request cost by your requests-per-day value and by 30. It is a simple workload projection, not a provider invoice forecast.

Does it include tools, search, grounding or storage fees?

No. Those charges can differ materially across providers and service tiers. The calculator is limited to direct text-token charges represented in the SXF pricing catalog.

How are long-context pricing rules handled?

If a model has a stored long-context rule, the calculator checks total input tokens and applies the cataloged multiplier automatically when the request crosses the stored threshold.
