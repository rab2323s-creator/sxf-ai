THE SHORT ANSWER

Which local LLM fits your GPU?

For an 8GB GPU, start with a compact 4B–8B quantized model, such as Qwen3 4B or Qwen3 8B at a modest context length. At 12GB–16GB, the published files for Qwen3 14B, Qwen2.5-Coder 14B and Gemma 3 12B become candidates. With 24GB–32GB, larger quantized options such as Qwen3 30B, Qwen2.5-Coder 32B and Gemma 3 27B are worth evaluating. None of these statements guarantees full-GPU loading at your chosen context length.

This is a hardware-selection guide, not a claim that one model wins all benchmarks. To install a runtime, use our Ollama vs LM Studio vs vLLM guide; for GGUF, AWQ and quantization tradeoffs, see LLM Quantization Explained.

04 / ENGINEERING REALITY

How much VRAM does a local LLM actually need?

Your GPU must hold more than model weights. Quantized file size is a useful starting point, but loading a local model also consumes space for execution buffers and a KV cache. A longer context or more simultaneous requests can increase memory demand. Multimodal inputs may add image-processing overhead.

For rough initial planning, this page compares the published Ollama download size + an explicit SXF headroom allowance. It is deliberately not a hardware benchmark. A model shown as a candidate may still spill onto system RAM or refuse to load at your chosen settings.

Why 4-bit vs 8-bit matters

A lower-bit quantized model generally uses fewer bytes for stored weights, but GGUF formats add metadata and different quantizers use different layouts. Q4_K_M, Q8_0, AWQ and GPTQ are not interchangeable in fidelity, compatibility or speed. Read our quantization guide and VRAM calculator before choosing a different variant.

GPU VRAM versus system RAM

On an NVIDIA or AMD discrete GPU, VRAM is separate from system RAM. Some runtimes can offload layers to the CPU, but that usually affects throughput and latency. Apple Silicon uses unified memory, so these discrete-GPU bands should not be interpreted as equivalent Mac RAM requirements.

06 / PRACTICAL QUESTIONS

Local LLM GPU & VRAM FAQ

What is the best LLM for an 8GB GPU?

There is no universal performance winner. For a source-backed starting point, Qwen3 4B (2.5 GB published download), Qwen2.5-Coder 7B (4.7 GB) and Qwen3 8B (5.2 GB) cover chat and code. With Qwen3 8B, reduce context or plan for offload if your system does not have enough runtime headroom.

Can a 12GB GPU run a 14B model?

Some 14B quantized artifacts are around 9.0–9.3 GB, leaving only a few GB before buffers, KV cache and OS use. A modest context configuration may work, but it is not guaranteed. The exact tag and runtime matter more than parameter count alone.

Which local coding LLM should I run with 16GB VRAM?

Qwen2.5-Coder 14B is a practical candidate with a published 9.0 GB Ollama download. Test it on representative repository edits and error fixing; a smaller 7B model may still be preferable for latency. These are workload suggestions, not head-to-head benchmark rankings.

Can I run a 30B model on a 24GB GPU?

Some quantized 30B model tags have download sizes around 19–20 GB. They can be candidates for 24GB cards at modest context, but KV cache and runtime buffers reduce available headroom. Long context or concurrency may force partial CPU offloading.

How is an Ollama model file size different from VRAM use?

The tag size describes downloaded model data, while runtime VRAM includes loading format, execution workspace, KV cache and sometimes image processing. Use ollama ps to see whether Ollama places a running model on GPU, CPU or both.

Can I run these models on a laptop or Apple Silicon Mac?

Many local models work on compatible laptops, but laptop GPU TGP, thermals, OS and available shared/system memory matter. Macs have unified memory rather than the dedicated VRAM bands in this page. See the full local inference setup guide for Apple Silicon and CPU-only considerations.

Is 4-bit quantization always the best choice?

No. A smaller quant may enable a bigger model or a larger context, but can affect quality and may behave differently across inference engines. Compare on your own prompts with the same runtime and settings. Learn about GGUF and 4-bit vs 8-bit.

Are these local AI models allowed for commercial use?

Licenses differ. The Qwen3 model card lists Apache-2.0, whereas Google Gemma models use Gemma-specific terms. Check the exact publisher card, associated files and current license before production use. The selector does not grant licensing rights.
