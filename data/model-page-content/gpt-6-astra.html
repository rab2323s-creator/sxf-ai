How much does GPT-6 Astra cost per million tokens?

OpenAI lists $10 uncached input, $1 cached-input read, $12.50 cache write and $50 output per million text tokens in Standard mode for prompts with up to 272,000 input tokens. For prompts with more than 272,000 input tokens, the entire request uses $20 input, $2 cached read, $25 cache write and $75 output per million tokens. The boundary is strictly greater than 272,000, not greater than or equal to it.

A request with 272,000 uncached input tokens plus 4,000 output tokens costs $2.92. Increasing input to 272,001 tokens raises estimated cost to $5.74002 because the higher rates apply to all request tokens, not only the additional token. This illustrates a discontinuity in published list-price billing; actual usage and fees may differ.

Method and reproducibility

For each request, input_total = new_input + cached_read + cache_write. If input_total > 272000, multiply all input and cache rates by 2 and the output rate by 1.5. Otherwise use short-context rates. Multiply each token count by its applicable per-million price and sum. The dataset contains modelled scenarios, not customer invoices. Cache-write counts assume those tokens are billed as writes; whether a request actually hits or writes cache depends on the serving system.

These scenarios deliberately fix output token counts. They do not predict reasoning-token consumption, completion quality, tool usage, failed retries or human-review costs. Read the source pricing policy alongside the CSV to reproduce the arithmetic.

GPT-6 Astra benchmarks: what do published results actually show?

In OpenAI's September 2026 release report, OSWorld 2.0 is 72.6% for Astra versus 65.7% for GPT-5.6 Sol; Agents' Last Exam is 59.3% versus 53.6%; and BenchCAD is 95.9% versus 83.3%. These are OpenAI-reported comparisons at the configurations defined by its launch report—not independent SXF measurements, universal pass rates or evidence that every real workflow will improve.

DEVELOPER REFERENCE

How to use GPT-6 Astra with the OpenAI Responses API

Set the exact gpt-6-astra model ID, choose a documented reasoning effort and validate the response before acting on real systems. Tool calling and structured outputs are supported; a model's output still requires independent checking for consequential work.

from openai import OpenAI

client = OpenAI()  # uses OPENAI_API_KEY from environment
response = client.responses.create(
    model="gpt-6-astra",
    reasoning={"effort": "high"},
    input="Review this migration plan. Identify assumptions, risks, and tests."
)
print(response.output_text)

For prompt-heavy workflows, observe actual billed new input, cached reads, cache writes and output tokens before using the SXF estimator as a budget. Also evaluate task accuracy, retries and human validation. See model capabilities and GPT-6 development guidance.

DECISION FRAMEWORK

GPT-6 Astra vs GPT-6.1 Sol: when is Astra worth paying for?

At short-context Standard list rates, Astra's uncached input and output tokens are five times GPT-6.1 Sol's. The price multiple is not a performance multiple. Start with a labelled evaluation set of your own tasks, then compare cost per accepted result rather than cost per token alone.

CHOOSE ASTRA TO TEST

Failure is costly

Complex computer use, multi-step coding, expert research and high-stakes document work where measured error reduction may offset more expensive tokens.

CHOOSE SOL AS BASELINE

Throughput and value matter

Routine-to-complex development and agent tasks with clearly testable acceptance criteria. Use GPT-6.1 Sol to benchmark economics before upgrading.

BEFORE DEPLOYMENT

Run a task-level pilot

Use held-out cases, record success and failure reasons, version the prompts and measure latency, API usage, tool charges and human corrections.
