MISTRAL EMBED / DEVELOPER ANSWER

What is Mistral Embed and when should you use it?

Mistral Embed is Mistral AI's general-purpose text embedding model for semantic search, retrieval-augmented generation (RAG), clustering, similarity and document classification. It accepts text and returns numerical embedding vectors, not natural-language answers. The December 2023 version is identified as mistral-embed-2312 in Mistral's model card, while its embedding API examples call mistral-embed. For practical SDK examples below we follow that documented API name and keep the versioned model-card ID distinct.

Mistral documents an 8,000-token input context, a Standard list price of $0.10 per million input tokens, and a 1,024-dimensional mistral-embed vector configuration in its Search Toolkit. Those figures describe an embedding service. No text-generation output-token rate, reasoning budget or conversational maximum output length applies. Mistral Embed is a Premier hosted API model, not an Apache-2.0 downloadable weight checkpoint.

Model selection warning — verified November 8, 2026

Mistral Embed is for general text similarity, while Codestral Embed is a separate model developed for source-code retrieval and offers documented output dimension/type controls. Do not reuse its $0.15/MTok price or adjustable dimensions as if they were guaranteed for Mistral Embed. For text RAG, the supported mistral-embed Search Toolkit preset uses 1,024 dimensions and cosine distance; verify your actual endpoint output before defining a persistent vector index.

How much space does a 1024-dimensional vector use?

A 1,024-dimensional embedding encoded as 32-bit floats has a theoretical numeric payload of 1,024 × 4 = 4,096 bytes per vector. That is 4.096 GB for one million vectors in decimal units, before document IDs, metadata, storage indexing, HNSW edges, replicas and database compression. This is independent mathematical analysis from SXF, not a measurement of any provider's vector database. Changing storage precision, sharding, indexing strategy or metadata can change actual footprint substantially.

COPYABLE DEVELOPER QUICKSTART

How to use the Mistral Embed API in Python and cURL.

Use the officially documented mistral-embed name with client.embeddings.create(). Keep your Mistral API key in server environment variables, not in public HTML or client JavaScript. An SDK returns data vectors and usage counters; vector dimensions should be checked before writing persistent indexes.

Python: embed documents and a query, then rank by cosine similarity

import math
import os
from mistralai.client import Mistral

documents = [
    "Refunds are available within 30 days.",
    "Support is available from 9 AM to 6 PM.",
    "Invoices are issued on the first of each month.",
]
query = "Can I return my subscription payment?"

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])
result = client.embeddings.create(
    model="mistral-embed", inputs=documents + [query]
)
vectors = [item.embedding for item in result.data]
query_vector = vectors[-1]

def cosine(left, right):
    dot = sum(a * b for a, b in zip(left, right))
    norm = math.sqrt(sum(a * a for a in left))
    norm *= math.sqrt(sum(b * b for b in right))
    return dot / norm if norm else 0.0

ranking = sorted(
    ((cosine(query_vector, vec), text)
     for vec, text in zip(vectors[:-1], documents)),
    reverse=True
)
for score, text in ranking:
    print(f"{score:.4f}  {text}")
print("Dimension:", len(query_vector))
print("API usage:", result.usage)

This example is an executable method based on official SDK patterns, but SXF has not run a paid embedding call for this page. Actual similarity scores depend on the model version and inputs and are not promised here. In production, map every vector to stable document/chunk IDs, enforce access filters and measure retrieval outcomes against labeled relevance judgments.

cURL: POST /v1/embeddings

curl "https://api.mistral.ai/v1/embeddings" \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mistral-embed",
    "input": [
      "Find the invoice policy.",
      "What are the refund rules?"
    ]
  }'

Mistral's REST endpoint uses input, while the current Python SDK uses inputs. Keep these differences separate. The REST interface offers optional output_dimension and output_dtype only where the selected model supports them; their presence in a shared schema does not guarantee that the 2023 Mistral Embed supports arbitrary dimensions or 8-bit output. Use Mistral's text embeddings examples to check syntax.

PRODUCTION RETRIEVAL ARCHITECTURE

Build a document RAG pipeline with Mistral Embed and a vector database.

  1. Extract documents with provenance. Parse PDFs and scans first, retaining page and source IDs. For scans, Mistral OCR 4.1 is a separate Document AI extraction service with per-page fees.
  2. Split content intentionally. Chunk by section, heading or sentence with limited overlap. Keep chunks within the 8K input limit, count tokens with supported tooling and avoid unnecessary overlap-driven token multiplication.
  3. Embed consistently. Embed document chunks and user queries with the same versioned/configured embedding space. Confirm expected 1,024-d output for mistral-embed in your environment.
  4. Store, filter, retrieve. Store vectors with tenant permissions and document IDs. Perform authorization filtering before revealing neighbors; combine cosine vector search with keyword/BM25 and a reranker when supported by measurements.
  5. Generate only after retrieval. Pass permission-checked, cited source passages to the separate answer model. Embedding similarity itself is not evidence that an answer is accurate or current.
  6. Evaluate and monitor. Measure recall@k, MRR, nDCG when graded judgments exist, citation validity, cold/warm latency and cost per accepted answer. Version the index and re-embed on model changes.

Review the SXF vector database architecture and filtering guide, RAG vs fine-tuning vs long-context trade-offs, and embedding model comparison. All three decisions—embedding model, retrieval storage and downstream generator—need independent measurement.

NO FABRICATED BENCHMARK WINNERS

Mistral Embed vs Codestral Embed vs Gemini Embedding 001.

These models serve related but different applications. Mistral Embed targets general text embeddings; Codestral Embed is optimized for source-code search; Gemini Embedding 001 is an external provider alternative with its own API, dimensionality controls and pricing. Their embedding vectors are not interchangeable: mixing them into one index invalidates naive distance comparisons even when vector dimensions match.

SEARCH INTENT FAQ

Mistral Embed FAQ: API pricing, 1024 dimensions, context, Python and RAG.

What is the Mistral Embed API model ID?

The model card names the December 2023 release mistral-embed-2312. Mistral's Python and REST embedding examples use mistral-embed.

How much does Mistral Embed cost per million tokens?

The published Standard Mistral Embed rate is $0.10 per million input tokens, with no separately published generated-text output-token rate. Vector database and RAG answer-model costs are separate.

How many dimensions does Mistral Embed produce?

Mistral's Search Toolkit pairs mistral-embed with a 1,024-dimensional cosine-distance vector preset. Check the returned array length in your own endpoint response before defining an index.

What is Mistral Embed's maximum context?

The official versioned model card lists 8,000 tokens per input. Use document chunking for texts longer than the limit.

Is Mistral Embed a text generation or reasoning model?

No. It maps text inputs into embedding vectors; it does not return chat answers, generated articles or reasoning token streams.

Is Mistral Embed open source and runnable locally?

The cited model is classified as a GA Premier embedding API, not an openly downloadable model-weight release. Do not confuse the hosted endpoint with Mistral's separate open-weight models.

Mistral Embed or Codestral Embed: which is better for RAG?

Start with Mistral Embed for general text search and Codestral Embed for code-specific retrieval. Benchmark actual query relevance, languages, cost and downstream answer quality rather than assuming one is universally better.

Can I use Mistral Embed with pgvector, Qdrant or Pinecone?

Yes. Store the model's vectors in a compatible index with the correct dimension and distance function. Use the same embedding model for document and query vectors and enforce access controls.
