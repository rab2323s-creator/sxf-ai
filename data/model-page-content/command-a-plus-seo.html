COHERE COMMAND A+ / DIRECT ANSWER

What is Cohere Command A Plus?

Cohere Command A+ (Command A Plus) is a multilingual, vision-enabled Mixture-of-Experts (MoE) language model released on May 20, 2026. Its exact Cohere API model ID is command-a-plus-05-2026. It combines text and image understanding, reasoning, tool calling, structured output and citations for enterprise agents and RAG applications.

The model has 218 billion total parameters, with 25 billion active parameters during inference, a 128,000-token context window and a 64,000-token maximum output. Cohere lists 48 languages, including Arabic and all official EU languages. It is distributed as open weights under Apache 2.0, with official W4A4 configurations designed for one NVIDIA B200 or two H100 GPUs.

Pricing distinction — verified November 8, 2026

Cohere's shared Chat API lists Command A+ as free until rate limits are reached for trial and production keys; this is not unlimited free production capacity. The company separately lists Model Vault Command A+ XL instances at $57.50/hour; the public pricing table does not list a Command A+ L rate, subject to access, tier and commercial commitment. Downloading Apache-2.0 weights does not make GPU infrastructure free. No universal Cohere paid input/output token rate is published for this API model, so SXF does not invent one.

EXACT MODEL-ID DEVELOPER GUIDE

How to call Command A+ with the Cohere Chat v2 API in Python and cURL.

Install the official cohere Python package, set CO_API_KEY server-side, and pin command-a-plus-05-2026. The official model documentation lists Chat v2, Chat Completions and legacy Chat v1 access. New integration examples should use /v2/chat rather than copying old /v1/chat request formats into the newer endpoint.

Python: basic multilingual task

import os
import cohere

co = cohere.ClientV2(api_key=os.environ["CO_API_KEY"])
response = co.chat(
    model="command-a-plus-05-2026",
    messages=[{
        "role": "user",
        "content": "Summarize the following support ticket in Arabic: "
                   "A customer cannot access their invoice portal."
    }],
    max_tokens=400,
    thinking={"type": "disabled"}
)
for block in response.message.content:
    if block.type == "text":
        print(block.text)

The example disables thinking to demonstrate a simple response; Cohere's reasoning documentation says thinking is enabled by default for reasoning-capable models. The thinking configuration also accepts a token_budget in supported requests. Set a useful response budget and measure real task accuracy and latency—these calls are documentation-based templates, not paid calls executed by SXF.

cURL: direct Chat v2 request

curl "https://api.cohere.com/v2/chat" \
  -H "Authorization: Bearer $CO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "command-a-plus-05-2026",
    "messages": [
      {"role": "user", "content": "Explain mixture-of-experts in two sentences."}
    ],
    "max_tokens": 300
  }'

Use Cohere's Chat API reference for current syntax and reasoning controls for thinking configuration. For structured JSON, verify response_format restrictions: the API docs warn that JSON mode does not combine with all tool/document configurations. Application-side schema validation remains necessary.

DIRECT SEARCH QUESTIONS

Command A Plus FAQ: price, model ID, context, license and GPUs.

What is the Cohere Command A+ API model ID?

Use command-a-plus-05-2026 with the Cohere Chat v2 endpoint /v2/chat or official ClientV2 Python SDK.

Is Command A+ free or paid?

The shared Cohere API is free until rate limits are reached for both trial and production keys. Standard Model Vault charges per managed instance-hour; the published Command A+ XL rate is $57.50/hour (no L rate listed), subject to access and commitments.

What is the Command A+ context window and output limit?

Cohere documents a 128,000-token context window and 64,000 maximum output tokens. Real request limits and available headroom depend on settings and platform.

Is Command A Plus open source?

Yes. Cohere released downloadable Command A+ weights under Apache 2.0. The model can be self-hosted on supported hardware but GPU, serving and operations costs remain separate.

How much GPU memory does Command A+ need?

Cohere documents a W4A4 configuration on one B200 or two H100 GPUs. The raw ideal 4-bit 218B checkpoint requires about 109 decimal GB of weight data before runtime overhead; a 25B-active parameter count does not imply dense 25B memory needs.

Does Command A+ support Arabic and vision?

Yes. Cohere lists 48 supported languages, including Arabic and EU official languages, with image and text inputs and text output.

Can Command A+ use reasoning and tools?

Yes. Cohere's Chat API supports configurable thinking and tool calls with citation options. Tools must be executed and authorized by the application; safety and structured-output combinations require validation.

Command A+ or Command A Reasoning: which is better?

Command A+ adds vision, 48 languages and a 218B/25B MoE structure but has a 128K context window; Command A Reasoning lists 256K context and 32K max output. Choose using your own quality, security, latency and cost tests, not a generic winner claim.
