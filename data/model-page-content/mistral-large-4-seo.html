MODEL GUIDE · OCTOBER 2026

Mistral Large 4: the quick answer.

Mistral Large 4 (ML4) is Mistral AI's flagship general-purpose multimodal, reasoning and agentic model, released in Public Preview on October 6, 2026. It accepts text and images, writes text, supports a 1-million-token context window, and is available via the Mistral Studio API. Its announced Mixture-of-Experts architecture has approximately 1.05 trillion total parameters and 52 billion active parameters according to Mistral's current model card.

For buyers, the immediate decision is its limited launch discount, API quality on your own documents and agent workflows, and the risk of deploying a preview model that may change before General Availability. Open-weight availability has been announced, but downloadable weights should not be assumed to exist until Mistral actually publishes them.

Fact check: 1M context is not an unlimited output allowance. Mistral has not published a separate verified max-output token count or knowledge cutoff in the source record used here. Do not treat these missing specifications as zeros or make up limits.

How to calculate a Mistral Large 4 API request

Estimate cost as (uncached_input × input_rate + cached_input × cached_rate + output × output_rate) / 1,000,000, where the rates are USD per million tokens. For example, a 150,000-token uncached prompt and a 20,000-token response cost $0.1438 at the launch prices or $0.2876 at standard regular prices. These are arithmetic examples, not measurements of response quality or actual user bills.

Actual billing can vary with Batch inference, priority or regional deployments, prompt caching eligibility, tools and account-specific terms. Read the official Mistral Large 4 card and Mistral's current pricing documentation before purchasing capacity. For general cross-model estimates, use SXF's model pricing explorer.

Architecture: why 1.05T parameters does not mean 1.05T active parameters

Mistral describes an expert-routed Mixture-of-Experts (MoE) model: the full network has about 1.05T total parameters, but only a subset is active for a token. The current model card reports 52B active parameters, plus a 1.6B vision encoder. The figures describe architecture, not throughput guarantees; actual speed depends on serving hardware and workload.

What is not independently verified yet?

Do not infer a maximum generated-output length, training-data cutoff, guaranteed requests per second, local GPU requirements, download URL or open-weight license from the 1M context figure or the preview announcement. These details depend on documented releases and serving configurations. As of this review, Mistral announced an open-weight release for later in October 2026; that is a forward-looking release plan, not proof that weights are already downloadable.

DEVELOPER QUICK START

How to use Mistral Large 4 with Python and the Chat Completions API.

Install the supported Mistral Python SDK with pip install mistralai, create a Mistral API key in Studio, and place it in the MISTRAL_API_KEY environment variable. The October 2026 API model name shown in the launch changelog is mistral-large-4. This example asks for a concrete, verifiable answer instead of relying on undocumented output parameters.

import os
from mistralai import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])
result = client.chat.complete(
    model="mistral-large-4",
    messages=[
        {"role": "system", "content": "Respond clearly. Cite provided evidence."},
        {"role": "user", "content": "List three checks for an invoice-review agent."}
    ],
)
print(result.choices[0].message.content)

Python example: ask Mistral Large 4 to reason more carefully

The official reasoning documentation lists reasoning_effort="high" for Mistral Large 4, with a none mode for minimal surfaced reasoning. In high mode, the response message.content can be structured as thinking and text chunks rather than a single string; production clients must handle that difference. Avoid logging private thinking content or exposing it to end users unnecessarily.

response = client.chat.complete(
    model="mistral-large-4",
    messages=[{
        "role": "user",
        "content": "Compare these three contract clauses for conflicting obligations."
    }],
    reasoning_effort="high",
)
content = response.choices[0].message.content
if isinstance(content, str):
    print(content)
else:
    for chunk in content:
        if getattr(chunk, "type", None) == "text":
            print(chunk.text)

USE CASES & TRADE-OFFS

What is Mistral Large 4 best used for?

CODING AGENTS

Repository understanding

Analyze multi-file code changes, propose plans, and connect function calls to testing tools. Gate shell access, production credentials and code execution behind explicit permissions.

ENTERPRISE KNOWLEDGE

Long reports and legal documents

Reason over many clauses, financial statements or requirements. Ask for page-level citations, validate figures and ensure human oversight for professional advice.

MULTIMODAL ANALYSIS

Charts, drawings and visual grounding

Inspect PDFs, equipment diagrams and images. Treat location and OCR claims as hypotheses to verify against originals.

RESEARCH & SCIENCE

Code-assisted analysis

Draft data-processing steps, simulation scaffolds and structured findings. Reproduce numeric results and use tests before relying on generated scientific code.

AGENTIC WORKFLOWS

Tool-connected processes

Use structured outputs and function calling to integrate business tools. Evaluate task completion, tool error recovery and security boundaries.

EU DEPLOYMENT PLANNING

European infrastructure options

Mistral describes plans for regionally managed deployment and future downloadable weights. Verify contractual residency, operational controls and weight availability individually.

When not to choose ML4: use a narrower model when strict latency, cost, speech generation or tiny on-device footprints matter most; use a specialized OCR or transcription service where fidelity on those tasks matters more than general reasoning. And because ML4 is still a preview, do not build irreversible compliance or safety-critical workflows around unverified performance claims.

SEARCH QUESTIONS ANSWERED

Mistral Large 4 FAQ: pricing, API, context, release and weights.

What is Mistral Large 4?

Mistral Large 4 is Mistral AI's October 2026 multimodal Mixture-of-Experts model in Public Preview. It supports text and image inputs, text outputs, reasoning, structured outputs and tool-connected workflows.

How much does Mistral Large 4 cost per million tokens?

Launch-period Standard prices are $0.68 input, $0.07 cached input and $2.09 output per million tokens through October 19, 2026 in SXF's verified rate schedule. From October 20 the listed regular rates are $1.36, $0.14 and $4.18 respectively. Confirm current pricing with Mistral before purchase.

What is the Mistral Large 4 context window?

The official model card lists a 1,000,000-token context window. This describes the model's context capacity, not a guarantee of perfect long-document recall or a separately published maximum output size.

What is the Mistral Large 4 API model ID?

The public-preview API is listed as mistral-large-4 in Mistral's launch changelog and model card. Reasoning documentation also mentions a versioned mistral-large-4-0 identifier. Check availability in your own Mistral Studio account.

Is Mistral Large 4 open source or downloadable?

Mistral announced open-weight plans for later in October 2026. At this review, the announcement is not proof of a downloadable release, and no license or hardware requirement should be assumed without an official weights publication.

Does Mistral Large 4 support images and PDF analysis?

Yes. Mistral lists multimodal text-and-image understanding and document Q&A. Production PDF handling should follow the documented API input type, with extracted results validated against source documents.

Does Mistral Large 4 support function calling and JSON outputs?

Yes. The official model card lists function calling, structured outputs, built-in tools and supported agent/conversation endpoints.

Can I use Mistral Large 4 from Python?

Yes. Install the mistralai SDK, set your MISTRAL_API_KEY variable and use client.chat.complete with model=mistral-large-4. See the runnable example above.

What is the difference between Mistral Large 4 and Mistral Medium 3.5?

Mistral Large 4 is a newer Public Preview model with a 1M context window. Mistral Medium 3.5 is a generally available coding and agent model with a 256K window. Compare cost, latency and task-level quality before choosing.

Is Mistral Large 4 ready for production?

It is accessible as a public preview, but Mistral's lifecycle policy allows preview models to receive updates and does not guarantee a transition to general availability. Use regression tests, controlled rollouts and fallback strategies.
