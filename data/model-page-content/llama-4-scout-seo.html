LLAMA 4 SCOUT / DIRECT ANSWER

What is Llama 4 Scout (17B-16E)?

Meta Llama 4 Scout is an open-weight, natively multimodal Mixture-of-Experts (MoE) model, first released April 5, 2025, for text understanding, visual question answering and very long-document analysis. It has 17 billion active parameters, 16 experts and 109 billion total parameters. These three numbers describe different parts of the model; Scout is not a dense 17B model.

Meta advertises a 10-million-token maximum context window for the instruction-tuned Scout variant, with text and up to five image inputs and text output. But the 10M figure is a published architectural/evaluation capacity, not proof that one H100 or every hosted inference endpoint accepts ten million tokens. Meta's 10M context evaluation used 512 GPUs with 5D parallelism; separately, a single 80GB H100 can run a limited-context, INT4-quantized Scout configuration. These are distinct workloads.

License and access caution — checked November 7, 2026

Scout's weights use the Llama 4 Community License, not Apache 2.0 or an unrestricted OSI open-source license. Meta's acceptable-use policy explicitly withholds certain license rights for EU-domiciled people and EU-headquartered organizations using its multimodal Llama 4 models (with an integrated-product end-user exception). Check the license section and official legal documents before downloading or deploying. An open-weight model is not automatically licensed for every location or use.

SXF ORIGINAL ENGINEERING MATH

Llama 4 Scout VRAM requirements: H100, INT4, FP8 and BF16 explained.

Meta publishes the Scout model as BF16 weights and documents a single 80GB H100 serving configuration via INT4 on-the-fly quantization. Its official reference also describes an FP8 mixed inference recipe needing two 80GB GPUs. This does not mean an ordinary 16GB or 24GB consumer card can load the full Scout checkpoint. CPU offload, expert placement and alternate quantization may change the setup but require independent verification.

LONG-CONTEXT EVIDENCE

Is Llama 4 Scout really a 10-million-token model?

Yes, for the published instruction-tuned Scout context capability—but this number needs three qualifiers. First, Hugging Face's Llama 4 release documentation distinguishes the 256K-context pretrained/original variant from the longer-context Scout Instruct variant. Second, Meta says the 10M evaluation used a large 512-GPU configuration. Third, hosted APIs can impose far lower endpoint limits; a provider's advertised “Llama 4 Scout” does not automatically expose Meta's full theoretical window.

A context window is the number of tokens the model can receive, not a measurement of retrieval accuracy at 10M tokens. Evidence buried in the middle of a very large prompt can still be missed or cited incorrectly. Run evaluation at the exact requested window, on the exact serving endpoint, with source-preservation checks. Also measure prefill time, memory peaks, dollars per successful answer and refusal/hallucination rate.

ACCESS AND DEPLOYMENT

How to download and run Llama 4 Scout locally with Transformers or vLLM.

For assistant-style applications, use Meta's official gated Llama 4 Scout 17B-16E Instruct checkpoint, not a generic “17B dense” file. Review and accept its license and access conditions first. A supported deployment path requires a runtime version that implements Llama 4's multimodal MoE layers, correct tokenizer/chat template, quantization method and enough accelerator memory.

Reference checklist for INT4 serving on server GPUs

  1. Legal access: confirm the Llama 4 license, usage policy, your jurisdiction and third-party hosting terms before obtaining weights.
  2. Checkpoint: use meta-llama/Llama-4-Scout-17B-16E-Instruct for conversational instruction following, and verify you are not loading an Original base checkpoint by mistake.
  3. Start from a known runtime: Meta's official inference repository describes int4_mixed on one 80GB H100 and fp8_mixed on two 80GB accelerators; follow its versioned requirements rather than assuming support for a consumer GPU.
  4. Serving and quantization: vLLM's published Llama 4 notes provide serving options. Pin a compatible vLLM and Transformers version, tokenizer, model revision, precision and accelerator architecture; consult the vLLM Scout serving guide.
  5. Start small: test 8K or 16K input tokens at batch size one; monitor real VRAM, out-of-memory errors, prefill duration and output correctness. Increase context only after repeatable tests.
  6. Document the endpoint limit: log max_model_len, input token counts, concurrent requests and the provider's real caps. A model-card “10M” number does not configure the serving stack automatically.

Illustrative Python usage after a compatible setup

import torch
from transformers import AutoProcessor, Llama4ForConditionalGeneration

model_id = "meta-llama/Llama-4-Scout-17B-16E-Instruct"
processor = AutoProcessor.from_pretrained(model_id)
model = Llama4ForConditionalGeneration.from_pretrained(
    model_id, torch_dtype=torch.bfloat16, device_map="auto"
)

messages = [{"role": "user", "content": [
    {"type": "text", "text": "Summarize the following in two sentences: ..."}
]}]
inputs = processor.apply_chat_template(
    messages, add_generation_prompt=True, tokenize=True,
    return_tensors="pt", return_dict=True
).to(model.device)
with torch.no_grad():
    ids = model.generate(**inputs, max_new_tokens=150)
print(processor.decode(ids[0][inputs["input_ids"].shape[-1]:], skip_special_tokens=True))

This is an illustrative Hugging Face API shape, not an SXF-tested one-GPU launch recipe. Plain BF16 loads need large accelerator resources (raw weights alone are about 218 decimal GB). For an 80GB H100 follow Meta's quantized recipe; the BF16 snippet above is intentionally unquantized and should not be assumed to fit there. Check the current model card and library compatibility before executing.

LEGAL AND COMMERCIAL CONTROLS

Is Llama 4 Scout open source and free for commercial use?

Llama 4 Scout provides downloadable weights subject to a custom license. It is open-weight but not an unconditional Apache 2.0 or MIT open-source release. The Llama 4 Community License permits a range of research and commercial uses under its terms, requires attribution and compliance with the acceptable-use policy, and has an additional license condition for organizations above 700 million monthly active users at the specified time.

EU limitation: Meta's Llama 4 Acceptable Use Policy states that Section 1(a) license rights for multimodal Llama 4 models are not granted to EU-domiciled individuals or EU-headquartered organizations. It separately carves out end users of products integrating such models. This is a substantive restriction and must not be hidden by a generic “commercially free” label. Host/platform terms may impose further conditions.

Before shipping a product, verify the actual entity using the weights, the location and permitted rights, distribution and attribution obligations, use restrictions, and any service-provider conditions. This is an editorial checklist, not legal advice or a claim of clearance. For broader model-governance questions, explore the SXF AI model licensing guide and AI agent security practices.

DIRECT SEARCH ANSWERS

Llama 4 Scout FAQ: 17B, 109B, 10M tokens, GPU and license.

Is Llama 4 Scout a 17B or 109B model?

It is a Mixture-of-Experts model with about 17 billion active parameters, 16 experts and 109 billion total parameters. Compute-active size and stored-weight size are different.

Can Llama 4 Scout really accept 10 million tokens?

Meta documents a 10M-token maximum for Scout Instruct and evaluated this scale on 512 GPUs. Your hosted API or local runtime may support a much smaller context. Verify the precise checkpoint and serving cap.

How much VRAM does Llama 4 Scout need?

Meta documents a single 80GB H100 INT4 configuration, not a 16GB consumer GPU setup. Raw 109B weights alone are approximately 54.5 decimal GB at ideal 4-bit precision and 218GB at BF16, before runtime and KV-cache overhead.

Where can I download Llama 4 Scout Instruct?

Use the gated official meta-llama/Llama-4-Scout-17B-16E-Instruct Hugging Face repository, subject to Meta's license, access rules and applicable law.

Is Llama 4 Scout free for commercial use?

Weights are distributed under the custom Llama 4 Community License, not a general-purpose OSI open-source license. Commercial use is subject to license terms, attribution, additional rights for very large services and a multimodal EU restriction in Meta's acceptable-use policy.

Does Llama 4 Scout support images?

Meta describes text and up to five image inputs with text output. The official model page specifies that image understanding is English-only.

What is the difference between Scout and Maverick?

Both use 17B active parameters. Scout contains 109B total parameters with 16 experts and a published 10M Instruct context, while Maverick contains 400B total parameters with 128 experts and a 1M Instruct context.

Does Meta publish an official Scout API price per token?

There is no universal direct Standard Meta token price for downloadable Scout weights in the SXF catalog. Hosted provider fees and context limits vary; self-hosting requires hardware and operational expense.
