DIRECT DEVELOPER ANSWER · ANTHROPIC MESSAGES API

How to use Claude Sonnet 5 API: Python example and testing checklist.

Call the Anthropic Messages API using claude-sonnet-5. Set ANTHROPIC_API_KEY securely in your backend environment. Do not expose credentials to browser code, public repositories or generated HTML. This code is an illustrative integration example, not an actual paid model call executed by SXF.

import anthropic

client = anthropic.Anthropic()  # reads ANTHROPIC_API_KEY
message = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=1024,
    messages=[
        {"role": "user",
         "content": "Review this pull request for correctness and risk."}
    ],
)
print(message.content[0].text)

How to compare before migrating to Sonnet 5.5

  1. Version a held-out set of actual engineering and agent tasks, with explicit acceptance criteria.
  2. Run the same prompts, tool policies and output-budget settings on the two exact IDs.
  3. Record input, cache-write, cache-read and output token counts alongside latency and success rates.
  4. Compare cost per accepted result and monitor the failure cases, rather than selecting models by the lowest input rate alone.

EVIDENCE / ORIGINAL DATA / LIMITATIONS

Sources and SXF research method: reproduce our token-cost calculations.

The SXF experiment applies Anthropic's dated Standard rate table to fixed hypothetical workloads. The repeated prefix sizes are 2,048, 16,000, 100,000 and 500,000 input tokens; request counts are 1, 2, 3, 10 and 100. Each request adds 2,000 new input tokens and 4,000 output tokens. A cache scenario bills the first prefix at the selected initial write rate and each later prefix at the published read rate. The uncached scenario bills each prefix at full input rates.

**Assumptions:** identical cacheable prefixes, all calls inside retention, eligible cache creation, successful cache hits, the same token counts across both models and no optional paid tools or other tier fees. The modelled 1M context is a serving limit, not a claim that every 500K-token prompt will be reliable. The downloadable original dataset publishes the numerical inputs, all six costs per scenario and the savings arithmetic. A source-backed automated test recomputes every row during site builds.
