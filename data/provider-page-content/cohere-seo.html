Which Cohere AI model should you choose?

Cohere builds language models and retrieval tools for enterprise AI. Its portfolio is not one interchangeable chatbot: Command generates and reasons over language, Embed converts text and images to search vectors, Rerank sorts search results by relevance, Parse extracts document content, and North includes specialized models for code and translation.

If you're building a knowledge assistant or RAG pipeline, the most useful stack may be Parse → Embed → vector/keyword retrieval → Rerank → Command. Each component serves a different purpose and can be evaluated or replaced independently. A Rerank API call will not generate a user-facing answer; an Embed vector will not summarize a PDF; and a Command model alone does not give you a current, searchable document index.

CHAT & AGENTS

Cohere Command models: A+ vs A Reasoning.

Command A+ is a general-purpose enterprise chat and agent model with visual input, multilingual capabilities, tool use, structured outputs and cited-document workflows. Cohere lists 128K context, 64K max output and an API ID of command-a-plus-05-2026. The vendor's model guide documents access with trial or production keys within rate limits, and separate dedicated deployment through Model Vault.

Command A Reasoning targets more deliberate, multistep problem solving and agent workflows, with 256K context and 32K max output in the verified catalog. The practical question is not simply which one has the longer context: evaluate how each handles tool failures, multilingual passages, instruction hierarchy, grounded citations and your actual response time budget.

For high-stakes document answers, combine Command with retrieved, access-controlled passages rather than asking it to recall private facts. Require citations to supplied evidence and use human checks for legal, financial and safety-sensitive decisions. Official Command A+ reference; Command A Reasoning reference.

SEMANTIC SEARCH

Cohere Embed models: v5 Pro vs v5 Fast vs Embed 4.

Embedding models transform a document and its query into mathematical vectors for semantic matching. They are commonly paired with a vector database and a separate reranking step. Cohere's Embed 5 family supports text, images and mixed text-and-image inputs with a 128K context and selectable vector dimensions including 256, 512, 768, 1,024, 1,536 and 2,048 (2,048 default), as listed in the current documentation.

QUALITY FIRST

Embed 5 Pro

Consider for difficult retrieval over complex business documents, multilingual material and offline indexing where higher latency may be acceptable.

LATENCY FIRST

Embed 5 Fast

Consider for interactive query-time embedding, frequent agent iterations and high-throughput use cases. Measure your own recall-latency trade-off.

EARLIER GENERATION

Embed v4.0

A multimodal retrieval option for existing deployments. Cohere lists 256–1,536 dimensions (1,536 default) and 128K context; test migration rather than assuming embeddings are interchangeable.

Important compatibility detail: Cohere documents that Embed 5 Pro and Fast share an embedding space, so a corpus embedded with one can be queried with the other in supported scenarios. That does not automatically extend to Embed v4 or other providers' embedding families. Changing vector dimensions or model generations may require rebuilding a vector index. Official Embed specifications; Embed 5 release notes (Sept 30, 2026).

SECOND-STAGE RETRIEVAL

Cohere Rerank 4 Pro vs Rerank 4 Fast.

Unlike embeddings, reranking starts with an existing set of candidate results. Given a search query and document snippets, Cohere's Rerank API returns a better relevance ordering and relevance scores. This makes it useful after vector search, hybrid retrieval or classic keyword/BM25 search.

COMPLEX DATA

Rerank 4 Pro

Choose as a test candidate where nuanced multilingual relevance, semi-structured JSON documents and quality matter more than raw throughput.

LOWER LATENCY

Rerank 4 Fast

Test for high-volume, interactive or cost-sensitive retrieval where reduced reranking latency and throughput are priorities.

Both tracked variants have a 32,768-token context specification in the provider catalog; that is not a generated-text output limit. The price unit for hosted Rerank can be a search: Cohere defines one search as a query plus up to 100 ranked documents, and longer documents may be chunked into additional units. Validate your typical document lengths before estimating costs. Rerank model guide; official billing explanation.

DOCUMENT INGESTION

Cohere Parse 5: extract PDFs, scans, tables and forms before RAG.

Parse 5 is a document-understanding model accessible through the Parse API. Cohere lists 8,192 context tokens and input support for PDF, PowerPoint and JPEG formats in its official guide. Its documented output is layout-aware Markdown with extracted text, tables, lists, forms, descriptions and page-position information—useful before indexing content for enterprise search.

Parse is not a substitute for a generative assistant or an embedding index. Cohere cautions that it does not return confidence scores for extracted content and that header/footer or typographic hierarchy may not be identified reliably. The API may also return different output representations depending on the requested format. Verify tables and figures before routing parsed text to an automated decision process. Official Parse guide.

TASK-SPECIALIZED MODELS

Cohere North Mini Code and North Small Translate.

North Mini Code targets repository-level coding and terminal-agent workflows. The tracked model card lists 256K context and 64K output. Evaluate whether its tool permissions, execution environment and deployment path fit your security needs before granting agent access to source repositories or shell commands.

North Small Translate specializes in multilingual translation with 16K input context and a 16K maximum output in the tracked catalog. Translation quality depends on language pair, domain terminology and formatting constraints: evaluate representative business texts, numbers and named entities rather than assuming every locale performs identically.

These are specialized models, not direct substitutes for Embed or Rerank. Confirm the current deployment channel, availability and open-weight license individually from Cohere's official model cards.

BUILD A PRACTICAL RAG SYSTEM

How Command, Embed, Rerank and Parse work together.

  1. Parse the inputs. Convert PDFs, tables and scans to structured text with Parse 5, retaining page numbers, permissions and original file references.
  2. Build embeddings. Chunk content and use Embed 5 Pro or Fast for vectors; store them in a secure vector index with metadata filters.
  3. Retrieve candidates. Combine vector similarity with keyword search if necessary, enforcing the current user's document permissions.
  4. Rerank the top candidates. Send the search query and candidate snippets to Rerank 4 Pro or Fast to improve result order.
  5. Generate a grounded answer. Give the best verified passages to Command A+ or a suitable Command model, requesting citations and recording sources.

This pattern separates indexing, retrieval quality and reasoning costs. It is not a claim that adding every endpoint always improves your system. Measure retrieval recall, ranking relevance, answer faithfulness, per-request latency and total cost on a labeled dataset. Cohere's official end-to-end RAG example.

PYTHON SDK · API V2

How to call Cohere models: Chat, Embed and Rerank examples.

Install the maintained SDK with pip install -U cohere, create a key in Cohere's dashboard and set the CO_API_KEY environment variable. Cohere V2 endpoints use cohere.ClientV2. Do not place API keys in client-side JavaScript or a public repository.

Generate text with Command A+

import os
import cohere

co = cohere.ClientV2(api_key=os.environ["CO_API_KEY"])
answer = co.chat(
    model="command-a-plus-05-2026",
    messages=[
        {"role": "user", "content": "Summarize three requirements for a secure RAG service."}
    ],
)
for item in answer.message.content:
    if item.type == "text":
        print(item.text)

Rerank search results with Rerank 4 Fast

docs = [
    "A refund may be requested within 30 days of purchase.",
    "Standard delivery takes three to five business days.",
    "Customers can reset their password in account settings."
]
ranking = co.rerank(
    model="rerank-v4.0-fast",
    query="How long do I have to request a refund?",
    documents=docs,
    top_n=2,
)
for match in ranking.results:
    print(match.index, round(match.relevance_score, 4), docs[match.index])

Create embeddings with Embed 5 Fast

vector_result = co.embed(
    model="embed-v5.0-fast",
    input_type="search_document",
    embedding_types=["float"],
    inputs=[{"content": [
        {"type": "text", "text": "Refund requests close after 30 days."}
    ]}],
)
print(vector_result)  # Embedding response, not generated prose

Model IDs, response shapes and optional fields may change between API versions and deployments; follow the official Chat reference, Embed reference and Rerank quickstart when adapting these snippets for production.

COHERE QUESTIONS ANSWERED

Cohere models FAQ: list, pricing, API and enterprise deployment.

What AI models does Cohere offer?

Cohere offers Command models for generation and agents, Embed for vector search, Rerank for ordering search results, Parse for document extraction, and North models for specialized coding and translation tasks. This SXF directory tracks 10 Cohere model pages as of October 2026.

Which Cohere model should I use for a chatbot?

Use a Command chat model such as Command A+ if it meets your language, tool, latency and deployment requirements. Embed and Rerank serve supporting retrieval tasks rather than replacing the answer-generation model.

What is the difference between Cohere Embed and Rerank?

Embed creates vectors so a search system can retrieve semantically similar items. Rerank takes a query and an existing set of candidate documents and orders those candidates by relevance. They are often used together.

What is Cohere Command A+?

Command A+ is a Cohere multimodal enterprise chat and agent model. The official model card lists 128K context, 64K maximum output, tool use, multilingual support, citations and structured outputs. Its API ID is command-a-plus-05-2026.

Is Cohere API access free?

Cohere provides free trial API keys with usage and rate limits; trial access is not unrestricted production access. Production API billing and dedicated Model Vault commitments depend on the model, plan and serving channel.

How does Cohere Rerank pricing work?

Hosted reranking is measured in search units: one query with up to 100 ranked documents is one search, while long documents may be split into additional chunks. The exact current per-search price depends on the plan; Model Vault uses a separate per-instance rate.

How much does Cohere Model Vault cost?

Published examples include $3 per hour for Embed 5 Pro Small, $5 per hour for Rerank 4 Pro Medium and $4 per hour for Parse 5 Medium, per dedicated instance. These are not per-token API rates; confirm current commitment and region terms.

Which model is better, Embed 5 Pro or Embed 5 Fast?

Cohere positions Embed 5 Pro for retrieval quality and Embed 5 Fast for lower latency and higher throughput. Cohere documents a shared embedding space between Pro and Fast. The best choice depends on your evaluation set and operating requirements.

When should I use Cohere Parse 5?

Use Parse 5 to extract text, tables, forms and layout information from PDFs, slides and images before indexing enterprise documents. It produces document representations and does not replace a chat model or vector search system.

Can I use Cohere models with Python?

Yes. Install the cohere package, authenticate with an API key and use cohere.ClientV2 with the Chat, Embed, Rerank or Parse endpoints. Models and supported API features can differ by endpoint and deployment.

Can Cohere models run privately?

Cohere offers dedicated Model Vault and private deployment options for supported models. Availability, capacity, terms and whether open weights can be self-hosted must be verified for the specific model and deployment region.
