READING THE VIEWS

Pareto means efficient, not universally best.

A model is Pareto-efficient when no other visible model is both better on the selected benchmark and better on the second axis. Cost uses the SXF Standard workload assumption of 100K uncached input + 10K output tokens; context uses the provider-published context window.
