DIRECT SEARCH ANSWER

What is Google Gemini 4?

Gemini 4 is Google DeepMind's next-generation multimodal reasoning family, initially led by Gemini 4 Argon. Google previewed Argon for a limited set of cyber defenders on September 30 and expanded access on October 13, 2026. The frontier model accepts text, images, audio, video and PDF files as inputs and generates text. It uses a sparse mixture-of-experts transformer architecture according to the official model card; Google does not disclose a public parameter count or local weights.

Gemini 4 Argon targets software engineering, enterprise analysis, scientific reasoning, multi-step autonomous workflows and multimodal understanding. Its API identifier is gemini-4-argon. Google's later Gemini 4 Carbon announcement on October 28 emphasizes long-horizon coding and cyber-defense. However, Carbon's early restricted rollout means it should not be presented as a standard public alternative with a working API endpoint yet.

Bottom line: for developers building an app today, use the documented Argon API. For assessing Google's claimed next frontier, read the Carbon announcement and its safety conditions—but distinguish announced performance from an accessible product.

UNIFIED CONTEXT / LONG DECODE

How does Gemini 4's 1M-token context and long decode work?

Gemini 4 Argon has a unified 1,048,576-token context. Input, intermediate thinking and output share that capacity. It is inaccurate to promise one million input tokens plus another million output tokens. Even if a request stays below the advertised limit, accuracy on a specific long-document task is not guaranteed.

01 / INPUTPrompt + multimodal files

Text, PDFs, audio and videos consume a portion of the shared token budget.

02 / REASONINGThinking tokens

Low, medium or high thinking can consume both output billing and shared context.

03 / RESPONSEVisible output + tools

Standard synchronous output is capped at 65,536 tokens; additional tool context may also count.

04 / EXTENDBackground long decode

Request more than 65,536 output tokens via background execution and join continuation steps.

For a response longer than 65,536 tokens, Google's Interactions API guide documents background=True with a larger max_output_tokens budget. Google may continue across multiple internal hops; applications must poll status, concatenate output steps and account for timeouts and retries. The maximum remains bounded by the combined context, and real cost rises with generated tokens.

REAL PRODUCT CAPABILITIES

Gemini 4 Argon multimodal inputs, tools and limitations

MULTIMODAL INPUT

Read documents, images, audio and video

Combine PDFs, video clips, speech and text prompts for multimodal analysis. The model's output remains text. Use task-specific validation for OCR, chart data, timestamps and financial/legal evidence.

PROGRAMMATIC TOOLS

Build agent workflows

Function calling, structured outputs, file search, Google Search grounding, URL context and code execution are documented. Computer use is in preview and should run in a confined environment with explicit approvals.

THINKING CONTROL

Match reasoning to the job

Low, medium and high thinking levels trade off reasoning effort, latency and billed generated tokens. Default medium is a starting point, not a universal optimization.

NOT SUPPORTED HERE

Do not confuse input and generation

Gemini 4 Argon does not expose audio generation, image generation or the Live API. Specialized image, speech and real-time models remain distinct products.

Tools can read sensitive pages, make changes or fetch untrusted material. Apply least privilege, confirmations for irreversible actions, prompt-injection checks, retry limits, logging and data retention controls before permitting an agent to operate autonomously. An LLM benchmark score cannot certify the security of an entire agent system.

OFFICIAL API QUICKSTART

How to use Gemini 4 Argon with Python and JavaScript

Use the public model ID gemini-4-argon. Google documents the Interactions API with the official google-genai SDK. The simple code below mirrors the primary-source quickstart and requires a paid API account with an authorized GEMINI_API_KEY.

Install Python SDK
python -m pip install -U google-genai
Python · Interactions API
from google import genai

client = genai.Client()
result = client.interactions.create(
    model="gemini-4-argon",
    input="Summarize three risks of autonomous coding agents.",
)
print(result.output_text)
JavaScript · Interactions API
import { GoogleGenAI } from "@google/genai";

const client = new GoogleGenAI({});
const result = await client.interactions.create({
  model: "gemini-4-argon",
  input: "Summarize three risks of autonomous coding agents.",
});
console.log(result.output_text);

Long-decode Python example: background execution

Python · long output
import time
from google import genai

client = genai.Client()
run = client.interactions.create(
    model="gemini-4-argon",
    input="Produce a detailed, source-aware engineering design.",
    background=True,
    generation_config={
        "max_output_tokens": 131072,
        "thinking_level": "high",
    },
)
while run.status in ("in_progress", "queued"):
    time.sleep(5)
    run = client.interactions.get(id=run.id)

text = "".join(
    part.text
    for step in run.steps if step.type == "model_output"
    for part in step.content if part.type == "text"
)
print(text)
print("Usage:", run.usage)

Deployment note: background execution is a documented capability, not a guarantee that every prompt needs or yields 131K tokens. Validate final status, handle timeouts/partial outputs, secure secrets in your environment and measure token usage. Follow Google's maintained long-decode guidance when SDK versions or API contracts change.

MODEL SELECTION, NOT BRAND HYPE

When should you choose Gemini 4 Argon instead of other AI models?

Consider Argon for Google-hosted multimodal analysis, long-context evidence work, complex reasoning, tool-connected coding and the Interactions API. Evaluate GPT-6 Astra or Claude Opus 5.5 as baselines for your exact coding, web-agent and long-document tasks; Google's own benchmark table shows that Argon does not lead every test. Consider smaller models for latency-sensitive, high-volume classification or low-cost tasks where a frontier reasoning model is unnecessary.

Use a 20–50-case task set, freeze prompt and tool permissions, compare exact outcomes and failure costs, measure the complete response including paid thinking and tool retries, and review safety exceptions. A vendor's headline rank is a discovery signal, not an empirical guarantee for your organization's workflow. See SXF's model comparisons and pricing index for broader decision frameworks.

READ BEFORE DEPLOYING

Known limitations, context accuracy and safety

  • Hallucinations: DeepMind's model card warns that generated results can contain errors, including on specialized professional tasks.
  • Long-context ≠ perfect recall: 1M tokens is an API size limit, not evidence of error-free retrieval from million-token prompts.
  • Paid thinking and tools: internal reasoning, function declarations and tool calls can contribute to billing, with extra search/grounding costs.
  • Platform and feature differences: Gemini app subscriptions, API usage and enterprise controls are separate, with different eligibility.
  • Carbon is not yet a generally available API replacement: don't guess its endpoint, context, parity or availability from Argon specifications.
  • Private weights not available: no published laptop quantization/VRAM figures for hosted Gemini 4 Argon.
  • Autonomous action requires guardrails: require confirmations for purchases, messages and production code changes, and isolate untrusted external content.

QUESTIONS PEOPLE SEARCH FOR

Gemini 4 Argon and Carbon FAQ

What is Gemini 4?

Google DeepMind's October 2026 frontier multimodal reasoning family. Argon is publicly available in the paid API; Carbon was announced later with limited initial access.

Is Gemini 4 Argon on the API?

Yes. Google's stable paid model identifier is gemini-4-argon, accessible through the Gemini API subject to account eligibility.

Can I call Gemini 4 Carbon from the public API?

No generally available Carbon endpoint was listed in Google's model catalog as of November 1, 2026. The October 28 rollout was limited to selected cyber defenders.

How many tokens are in Gemini 4 Argon's context window?

1,048,576 total, shared by input, thinking and output. A standard synchronous call has a 65,536 output ceiling unless you use background long decode.

What is Gemini 4 API pricing?

Argon's announced introductory paid rate is $2 per million input and $10 per million generated tokens through November 30, 2026, then $4 and $20 from December 1. Thinking tokens are billable output.

Is Gemini 4 Argon free to use?

Not through the Gemini API Free tier. Google AI Pro or Ultra subscriptions in the consumer app are different from API metering.

Can Gemini 4 Argon create images or speech?

Argon accepts audio, video and image inputs, but outputs text. Google's API spec does not support native image or audio generation or the Live API for Argon.

What tools does Gemini 4 Argon support?

Function calling, structured output, Search grounding, URL context, code execution and more, subject to features and permissions; computer use is listed in preview.

Can I turn Gemini 4 thinking off?

Argon supports low, medium and high; medium is the default. There is no documented off setting for this model.

Is Gemini 4 Argon better than GPT-6 Astra?

It depends on the benchmark. Google's October model card shows Argon ahead on Vals Index but behind Astra on FrontierSWE v2; test your own workload.

Can I run Gemini 4 locally?

Google has not released Argon's model weights for self-hosting, so generic RAM or quantization estimates would be misleading.

What is different about Gemini 4 Carbon?

Google presents Carbon as a later, stronger frontier and cybersecurity model, with October 28 restricted testing. Availability, API naming and technical limits should not be inferred from Argon.
