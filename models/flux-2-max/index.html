QUICK MODEL ANSWER

What is FLUX.2 Max?

FLUX.2 [max] is Black Forest Labs' premium model for text-to-image generation and reference-guided image editing. It is positioned for high-fidelity marketing visuals, realistic product photography, character consistency and complex visual instructions. Unlike a text chatbot, its main output is an image, not a token stream.

At a glance: generate up to 4-megapixel images, pass as many as 8 reference images through the BFL API (10 in its Playground), and use the hosted /v1/flux-2-max endpoint. Direct BFL API pricing starts at $0.07 for the first output megapixel. Max is also the FLUX.2 variant with grounding search for incorporating real-time information when prompted. Black Forest Labs confirms the model's positioning.

OFFICIAL API PRICING

FLUX.2 Max price per image: examples and billing formula.

The frequently quoted $0.07 price is only the first output megapixel. BFL's official rate card charges $0.07 for output MP #1, +$0.03 for each additional output MP, and +$0.03 per billed reference-image MP. A megapixel in BFL's pricing definition is 1024×1024 pixels, and output and reference sizes are rounded up to whole billable MP. Output is limited to 4 MP.

Base cost formula: $0.07 + $0.03 × (billed output MP − 1) + $0.03 × billed reference MP. Use this for the official BFL API price; do not automatically apply it to third-party providers.

HIGH-VOLUME COST

$7 / 100 images

Illustrative cost for 100 successful 1MP text-to-image outputs; larger images, editing references and provider-specific fees increase cost.

Multi-reference billing nuance: a single reference can be processed up to 4MP at its original size. With multiple reference images, BFL says sources over 1MP are reduced to 1MP and every reference is charged as one MP. Images above 4MP are resized. These rules mean input count and output dimensions both matter when estimating image-editing cost.

GENERATE VS EDIT

How to use FLUX.2 Max for image generation and editing.

TEXT TO IMAGE

Create an asset from a prompt

Describe the subject, layout, material, lighting, lens and intended usage. For example, produce a realistic product hero image or key visual for a campaign without a reference photograph.

Example: “Studio product shot of a frosted amber skincare bottle on pale travertine, soft side lighting, 85mm lens, subtle shadows, label reading ‘SOLIS’, restrained editorial layout, 4:5 portrait composition.”

IMAGE EDITING

Keep the identity, change the scene

Attach the original image using input_image and specify what to modify while preserving important elements. The reference can define the product, character, wardrobe or architecture.

Example: “Use the bottle from image 1. Preserve its silhouette, cap and logo layout. Replace the background with a sunlit bathroom vanity, maintain natural contact shadows and keep the brand color #A65E45.”

MULTI-REFERENCE COMPOSITING

Combine several visual sources

Use one image for the subject, a second for a prop and a third for the environment, and refer to the numbered images in the prompt. This is useful for campaign consistency but adds reference-input cost.

Example: “Place the chair from image 1 in the room from image 2. Apply the fabric texture in image 3 while retaining the chair's shape, scale and perspective.”

BFL's text-to-image documentation and image-editing guide explain the two request patterns. For branding, review each generated letter, packaging claim and legal mark before publishing.

DEVELOPER REFERENCE

FLUX.2 Max API: endpoint, parameters and example request.

Use POST https://api.bfl.ai/v1/flux-2-max with your private BFL API key in the x-key header. The JSON body includes a required prompt, optional image dimensions such as width and height, and optional image references such as input_image and input_image_2. BFL's API also documents an optional seed, output_format and disable_pup setting. Confirm the exact feature set in your current API reference.

Minimal text-to-image cURL example:

curl -s -X POST "https://api.bfl.ai/v1/flux-2-max" \
  -H "accept: application/json" \
  -H "x-key: $BFL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Photorealistic ceramic coffee mug on a walnut table, morning window light, shallow depth of field",
    "width": 1024,
    "height": 1024,
    "output_format": "jpeg"
  }'

To edit an existing image: use the same endpoint and add "input_image": "https://example.com/source.jpg" to the payload, together with a prompt identifying the desired change. Additional reference fields follow the numbered pattern through input_image_8.

01

Submit: authenticate server-side with BFL_API_KEY. The API returns a job identifier and a polling_url, not finished image bytes immediately.

02

Poll: request the returned polling_url until status becomes Ready. Handle failed or moderated requests and apply retry limits.

03

Save: retrieve the signed image URL under result.sample promptly; BFL says result links expire after about ten minutes.

04

Secure: never expose the API key in website JavaScript or share generated output links as permanent asset storage.

Official integration references: BFL submit-and-poll quickstart and editing request example.

DISTINCTIVE FEATURE

What is FLUX.2 Max grounding search?

Black Forest Labs identifies grounding search as a Max-only FLUX.2 capability. When the prompt calls for timely context, the model can search the web and incorporate information into an image. BFL examples include weather-inspired city visualizations and topical graphics. This can be valuable when the visual should reflect current context rather than the model's static learned associations.

Practical limitation: grounding is not an independent fact-checking service. If the visual displays financial data, current weather, news, public figures or numerical claims, verify the output and its labels against authoritative external sources before publishing. BFL does not claim that grounding makes every generated statement error-free.

Source: BFL FLUX.2 text-to-image guide: Grounding Search.

PROMPTS AND QUALITY CONTROL

How to write effective FLUX.2 Max prompts.

01

Start with the final composition: specify subject, environment, viewing angle, crop and main visual hierarchy before adding aesthetic adjectives.

02

Specify exact brand constraints: include key colors as hex values, desired materials and precisely quoted text. Then inspect letter shapes, small print and logos in the generated output.

03

In editing, define both changes and invariants: tell the model what to replace and what must retain identity, scale, face, packaging or lighting.

04

Use numbered references intentionally: identify which image supplies the person, product, style or location rather than asking it to infer the source of each element.

05

Test at your final output size: megapixel cost grows with dimensions, and 4MP is the supported ceiling. Compare samples at the resolution you intend to publish.

These are practical production recommendations based on documented FLUX.2 prompting capabilities, not a guarantee that every prompt will produce identical or perfectly legible results.

FREQUENTLY ASKED QUESTIONS

FLUX.2 Max FAQ: pricing, images, API and editing.

01

What is FLUX.2 Max? FLUX.2 [max] is Black Forest Labs' premium FLUX.2 image-generation and image-editing model. It emphasizes high visual fidelity, consistency across reference images, detailed prompt following and optional grounding search.

02

How much does FLUX.2 Max cost per image? On Black Forest Labs' API, the first output megapixel costs $0.07, each additional output megapixel adds $0.03, and reference-image inputs cost $0.03 per billed input megapixel. Thus a 1024×1024 text-to-image result starts at $0.07, while a 2048×2048 four-megapixel result costs $0.16 before any reference-image input.

03

What is the FLUX.2 Max API endpoint? Black Forest Labs documents POST https://api.bfl.ai/v1/flux-2-max with the x-key API key header, a prompt, and optional parameters such as width, height, seed, output_format and input_image fields. Requests are asynchronous.

04

Does FLUX.2 Max support image editing? Yes. Supply an input_image and describe the requested change. Up to eight reference images can be supplied through the BFL API, while its Playground supports up to ten.

05

What is the maximum FLUX.2 Max resolution? FLUX.2 supports output images up to 4 megapixels; 2048×2048 is a four-megapixel example. The official resolution guidance lists minimum dimensions of 64×64 pixels and dimension increments of 16 pixels.

06

What is grounding search in FLUX.2 Max? Grounding search is a capability specific to FLUX.2 [max] that can search the web when prompted to incorporate timely context into images. Generated visuals should still be fact-checked against original sources.

07

Is FLUX.2 Max free or open source? The BFL-hosted FLUX.2 [max] API is a paid service. Do not confuse it with the locally deployable FLUX.2 [dev] or [klein] releases, whose weight licensing and access are separate.

08

FLUX.2 Max vs FLUX.2 Pro: which should I choose? Choose Max for premium fidelity, difficult multi-reference editing and grounding search; choose Pro for a lower-cost production workflow. Official BFL rates start at $0.07 for Max versus $0.03 for Pro for the first output megapixel. Output quality and speed depend on task and settings.

09

How does FLUX.2 Max image editing pricing work? Editing adds reference-image input charges to output-resolution charges. For example, a 2MP output plus two one-megapixel references is $0.10 for output plus $0.06 for input, totaling $0.16 at BFL's published rates. Multiple references have special resizing rules.

10

How should I prompt FLUX.2 Max for product photography? Define the product, composition, camera angle, background, lighting and any required brand colors. When editing, identify the elements that must stay unchanged and describe the exact modification; test the generated logo and text before publishing.

CAVEATS

What the source record does not assume.

01

Official base price is $0.07 for the FIRST output megapixel (MP, 1024×1024). Each ADDITIONAL output MP is +$0.03, and image reference input is $0.03 per input MP. The displayed $0.07 is therefore a STARTING price, not a universal image cost.

02

Input and output resolutions round upward to whole megapixels separately. Output is capped at 4 MP; multiple references have provider-specific resize and billing rules.

03

FLUX.2 Max is available on BFL's API and other supported runtimes including Cloudflare Workers AI. The flat text-token calculator is not applicable.

04

Do not confuse FLUX.2 Max with newer FLUX 3 Image or other FLUX.2 variants.
