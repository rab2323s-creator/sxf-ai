QUICK ANSWER

Grok 4.6 at a glance.

Grok 4.6 is xAI's August 2026 frontier model for coding, agentic work and knowledge tasks. It accepts text and images, has a 500K-token context window, supports configurable reasoning, function calling and structured outputs, and has no separately documented text-output cap.

For short-context API requests, xAI lists $2.00 input, $0.50 cached input and $6.00 output per million tokens. Long-context requests use higher rates once the prompt reaches the documented threshold.

CURRENT STATUS

Grok 4.6 is still available, but Grok 4.7 is newer.

Grok 4.6 remains an xAI API model and is still useful for production integrations that already depend on its behavior, pricing or regression profile. For a new deployment, Grok 4.7 is the newer generation and should normally be included in the evaluation set rather than assuming 4.6 is still the best xAI choice.

That does not make Grok 4.6 obsolete as a reference target: existing applications, benchmark baselines, partner integrations and cost models still need a precise 4.6 record.

Grok 4.6 pricing, including long context.

xAI uses a second token-rate tier when the request reaches the long-context threshold. The long-context rates apply to the entire request, not only the tokens beyond the threshold.

WHAT IT IS FOR

Where Grok 4.6 is strongest by design.

xAI describes 4.6 as a model built especially for long-running agents and more ambitious interactive and visual work.

CODING AGENTS

Work across a codebase

Grok 4.6 was trained and evaluated for software-engineering trajectories that span planning, implementation, testing and refinement rather than one-shot code completion.

LONG-RUNNING AGENTS

Stay with multi-step tasks

xAI emphasizes workflows that require sustained progress across many steps, with more self-testing and verification observed on longer trajectories.

KNOWLEDGE WORK

Research and analyze information

INTERACTIVE / VISUAL WORK

Turn ideas into working projects

xAI reports stronger first passes on interactive and visual projects than Grok 4.5, including application structure and visual language.

GROK 4.6 VS 4.5

The 4.6 release targeted longer agentic work.

xAI says Grok 4.6 builds on Grok 4.5 with a longer supplemental training run, curated reasoning and engineering data, and additional agentic reinforcement learning. In xAI's launch table, Grok 4.6 scored above Grok 4.5 on every listed evaluation.

The largest practical distinction is not a headline context-window increase—both generations were positioned for large-context work—but the stronger emphasis on sustained coding, knowledge-work and self-verifying agent trajectories.

PRICE DIFFERENCE Headline input/output pricing stayed at $2 / $6.

Current xAI pricing lists Grok 4.5 cached input at $0.30 per 1M versus $0.50 for Grok 4.6, while both use higher rates at the long-context tier.

LIMITS & CAVEATS

What to keep in mind.

01

No separate output cap does not mean infinite generation. Input, reasoning and output still share the model's finite context budget.

02

Long context changes economics: a request at the threshold moves the entire request to the higher token-rate tier.

03

Vendor benchmarks need context: xAI's launch scores are useful evidence, but they are not a replacement for task-specific evaluation.

04

4.7 is the successor: check the newer model before standardizing 4.6 for a new application.

FAQ

Grok 4.6 questions, answered.

What is Grok 4.6?

Grok 4.6 is xAI's frontier reasoning model released on August 12, 2026 for coding, long-running agents, knowledge work and ambitious interactive or visual projects.

What is the Grok 4.6 context window?

xAI documents a 500,000-token context window for Grok 4.6, with text and image input and text output.

How much does Grok 4.6 cost?

For prompts below 200,000 input tokens, Grok 4.6 costs $2 per million input tokens, $0.50 per million cached input tokens and $6 per million output tokens. At 200,000 input tokens and above, the documented rates are $4, $1 and $12 respectively, and those rates apply to the entire request.

Does Grok 4.6 support function calling?

Yes. xAI lists function calling and structured outputs as supported Grok 4.6 capabilities.

What reasoning levels does Grok 4.6 support?

Grok 4.6 supports low, medium, high and xhigh reasoning effort. xAI documents high as the default.

Does Grok 4.6 support images?

Yes. Grok 4.6 accepts text and image input and returns text output.

What are the Grok 4.6 API rate limits?

The xAI model page currently lists 150 requests per second and 50,000,000 tokens per minute for Grok 4.6.

Does Grok 4.6 support the Batch API?

No. xAI currently lists Batch API support as not supported for Grok 4.6.

Is Grok 4.6 better than Grok 4.5?

xAI reported higher Grok 4.6 scores than Grok 4.5 across every benchmark in its Grok 4.6 launch table, with especially large gains on long-running agentic and coding evaluations.

Should I use Grok 4.6 or Grok 4.7?

Grok 4.7 is the newer generation and should usually be evaluated first for new deployments. Grok 4.6 remains available and can still be appropriate for existing integrations, regression-sensitive workloads or cases where your own evaluations favor it.
