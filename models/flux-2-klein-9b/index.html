FLUX.2 KLEIN 9B / DIRECT ANSWER

What is FLUX.2 Klein 9B?

FLUX.2 [klein] 9B is Black Forest Labs' nine-billion-parameter, step-distilled image model for text-to-image generation, image editing and multi-reference composition. The distilled version uses four inference steps; the undistilled 9B Base is a different checkpoint intended for customization and fine-tuning. It is not a text chatbot and has no meaningful publicly specified token context window.

For developers, the important choices are hosted API versus local weights, distilled versus Base, and whether a roughly 20–24 GB GPU budget is available. The hosted BFL API starts at $0.015 for the first billed output megapixel; local 9B weights carry a FLUX Non-Commercial License. BFL lists 19.6 GB VRAM for its distilled 9B reference configuration, but advises planning around 24 GB for local use. These are different claims, not a universal minimum.

DEVELOPER QUICKSTART

How to use the FLUX.2 Klein 9B API.

Create a Black Forest Labs API key, send a text prompt to the flux-2-klein-9b endpoint, then follow the asynchronous result flow described in the official API documentation. A basic request has the following shape:

curl -X POST "https://api.bfl.ai/v1/flux-2-klein-9b" \
  -H "x-key: $BFL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Studio product photograph of a ceramic mug on a neutral backdrop, soft side lighting","width":1024,"height":1024}'

The API key must stay on the server; never expose it in client-side JavaScript or a public repository. Confirm accepted dimensions, reference-image fields, status polling and delivery URLs in the live BFL API reference. An image-editing workflow adds an input image and an explicit instruction to retain or change named details; source-image size can affect cost.

Example editing prompt: “Replace the background with a bright kitchen, retain the mug's exact handle shape, logo and ceramic texture, and preserve its original viewing angle.” Evaluate logo accuracy and object preservation before accepting the result; prompt text cannot guarantee pixel-perfect consistency.

LOCAL INSTALLATION

FLUX.2 Klein 9B in ComfyUI: weights, files and setup.

For local ComfyUI use, update ComfyUI, obtain the licensed 9B checkpoint from BFL's Hugging Face model repository, accept the repository's access terms and follow ComfyUI's FLUX.2 Klein workflow tutorial. Choose the 9B workflow rather than accidentally mixing 4B text encoders and diffusion files.

If hardware is tight, investigate the 4B Apache-licensed variant or the newer FLUX 3 Image Klein local setup guide rather than conflating generations.

LEGAL / DEPLOYMENT CHOICE

Is FLUX.2 Klein 9B free for commercial use?

No—not merely because its weights are downloadable. Black Forest Labs makes the FLUX.2 Klein 9B local weights available under the FLUX Non-Commercial License. For commercial use of self-hosted 9B weights, obtain the proper BFL license. BFL says commercial rights are included when using its paid hosted API, subject to the applicable terms. By contrast, the Klein 4B weights use Apache 2.0. Read BFL's licensing explainer.

Before deploying, document whether you are calling the API or shipping weights, whether outputs enter client work or model training, and which license applies. Training on generated outputs may require separate synthetic-data rights. See the site's AI model licensing due-diligence guide for a broader verification checklist. This is an operational summary, not legal advice.

SXF REPRODUCIBLE EVALUATION METHOD

How SXF recommends testing Klein 9B quality, cost and latency.

We do not publish a fabricated SXF speed test, fidelity score or benchmark winner. Instead, this is an original six-task evaluation protocol a team can replay against Klein 9B, 4B and Pro to decide whether a lower per-image fee produces cheaper usable output:

  1. Prompt fidelity: produce a three-object studio scene with specified materials, positions and background; check every named constraint.
  2. Typography: render a short, fixed five-word sign; record exact spelling, punctuation and placement.
  3. Product consistency: edit a supplied product photo; score logo, geometry, color and texture preservation.
  4. Two-reference compositing: combine a product reference and a background reference without unintended identity changes.
  5. Latency: repeat each task at fixed output dimensions and capture end-to-end p50/p95 time, including any polling and downloads.
  6. Economics: retain failed generations and retries; compute total generation spend / accepted outputs instead of per-attempt price.

Record model/checkpoint version, seed where supported, hardware, precision, inference steps, input images, dimensions, prompt, acceptance rubric and all failures. Keep model-generated outputs and external reviewer judgments separate. Results from BFL's own hardware are vendor-reported reference measurements until independently reproduced. This protocol is guidance, not a claim that SXF has already executed the benchmark.

COMMON QUESTIONS

FLUX.2 Klein 9B FAQ: API, ComfyUI, GPU and license.

How much does FLUX.2 Klein 9B cost per image?

Direct BFL API billing starts at $0.015 for the first billed output megapixel; further output MP and reference-image input MP cost $0.002 each at the published rate. The full price varies by billed image dimensions.

What is the FLUX.2 Klein 9B API endpoint?

Use POST https://api.bfl.ai/v1/flux-2-klein-9b and authenticate with an x-key API key header. Consult the official API documentation for request parameters and asynchronous result handling.

Does FLUX.2 Klein 9B work in ComfyUI?

Yes. ComfyUI publishes dedicated FLUX.2 Klein 9B text-to-image and image-editing workflows and lists the matching diffusion, Qwen3 8B text-encoder and VAE files.

How much VRAM does Klein 9B need?

BFL's distilled model table lists 19.6 GB in its reference configuration and its local-use support guidance suggests around 24 GB. CPU offloading, quantization and workload configuration can alter requirements.

Is the 9B model open source and free for commercial use?

Its weights can be downloaded, but their license is FLUX Non-Commercial, not Apache 2.0. Commercial local deployment requires appropriate rights; BFL's hosted API includes commercial usage rights under its terms.

What is the difference between Klein 9B and Klein 9B Base?

9B is the four-step distilled model for fast inference. 9B Base is the undistilled checkpoint designed for fine-tuning and greater control, with different speed and memory characteristics.
