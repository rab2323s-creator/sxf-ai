DEVELOPER GUIDE · VERIFIED AWS DOCUMENTATION

What is Amazon Nova 2 Lite?

Amazon Nova 2 Lite is Amazon's cost-conscious multimodal reasoning model, launched on December 2, 2025 and served through Amazon Bedrock. It reads text, images, documents and video and generates text. AWS positions it for customer support, document understanding, software assistance and multi-step agents where throughput and operating cost matter.

Its headline specifications are a 1,000,000-token context window, a 64K-token maximum output listed on the Bedrock model card and an October 2025 knowledge cutoff. Extended thinking is optional: keep it off for simpler extraction or summarization, and switch to low, medium or high effort for tasks that benefit from additional reasoning. It is not an image-generation, text-to-speech or audio-transcription model.

Amazon Nova 2 Lite API pricing: input, output and real examples.

At the tracked Standard reference rates, Nova 2 Lite costs $0.30 per million input tokens and $2.50 per million output tokens. The effective charge depends on the selected AWS Region, inference profile, service tier, caching, batching and usage type. Compare your configured route against the current Amazon Bedrock pricing before estimating production spend.

How to estimate a Nova 2 Lite request

Multiply input tokens / 1,000,000 by the input rate, then add output tokens / 1,000,000 times the output rate. If your application generates extra reasoning tokens or uses optional tools, include the relevant metered usage. For high-volume document jobs, measure token usage from actual Bedrock responses instead of estimating from page count alone.

A June 2026 AWS document-processing example explains that Nova 2 Lite now uses fixed per-image billing in that workflow, with 230 input tokens for one image. AWS estimated approximately $0.0027 per page for its specific extraction prompt and output lengths; that is an AWS example, not a flat price for all PDF or image requests. See the method and cost assumptions.

Some Bedrock tiers offer different economics. Standard, Flex, Priority, Batch and cross-Region choices should not be treated as interchangeable. Review the SXF model pricing explorer and token cost calculator for broader planning.

SPECS & LIMITS

1M context, 64K output, supported modalities and limitations.

ACCEPTS

Text, images, documents and video

Analyze contracts, screenshots, product photos, scanned pages or video frames. Use the documented input format and per-request limits for each media type.

GENERATES

Text responses

Use Nova 2 Lite for analysis, structured textual answers, classification and code help; it does not natively produce audio, generated images or video.

REASONING

Off by default

Explicitly enable low, medium or high extended thinking when a task warrants the additional latency and chargeable tokens.

The million-token context is a capacity ceiling, not a promise of perfect recall or unlimited output. For long contracts or large codebases, split and label sources, request evidence-backed answers, and evaluate recall on your actual documents. AWS lists a 64K output maximum on the Bedrock model card; SDK/runtime generation settings may impose lower effective limits.

For video, AWS documents frame-based understanding rather than soundtrack comprehension: do not rely on Nova 2 Lite to transcribe the audio track of a video. Dedicated speech models are a better choice when audio input is the central task. For documents, validate detected text, positions and numerical data before taking automated actions. PYTHON EXAMPLE

How to call Amazon Nova 2 Lite with Boto3 and Bedrock Converse.

Install boto3, configure AWS credentials and ensure the calling role has permission to invoke Amazon Bedrock models. Use an inference profile available in your Region. This minimal example returns the model's text answer using the Converse API and a global cross-Region profile; choose a geo profile instead if data-residency rules require it.

import boto3
from botocore.config import Config

client = boto3.client(
    "bedrock-runtime",
    region_name="us-east-1",
    config=Config(read_timeout=3600),
)
response = client.converse(
    modelId="global.amazon.nova-2-lite-v1:0",
    messages=[{
        "role": "user",
        "content": [{"text": "Summarize three causes of shipping delays."}]
    }],
    inferenceConfig={"maxTokens": 400},
)
for block in response["output"]["message"]["content"]:
    if "text" in block:
        print(block["text"])
print(response.get("usage"))

For reasoning-intensive tasks, replace the basic call's inferenceConfig with the following argument. The response may include redacted reasoning blocks; inspect text blocks separately. AWS notes that high reasoning effort is incompatible with settings such as maxTokens, temperature, topP and topK, so omit those settings when using high effort.

additionalModelRequestFields={
    "reasoningConfig": {
        "type": "enabled",
        "maxReasoningEffort": "low"
    }
}

Model IDs: amazon.nova-2-lite-v1:0 is the base model ID; global.amazon.nova-2-lite-v1:0, us.amazon.nova-2-lite-v1:0 and eu.amazon.nova-2-lite-v1:0 are distinct routing profiles. Check active regional support before copying an ID. Converse documentation and model-ID reference.

DECISION GUIDE

When should you enable extended thinking?

Use reasoning off for routine text rewriting, extraction or classification when your evaluation set shows acceptable accuracy. Try low effort first for instructions with several constraints or multi-step workflows. Progress to medium or high only if the quality gain is meaningful relative to extra latency and output-token charges.

Reasoning is not the same as live internet access. Nova 2 Lite supports separately configured built-in web grounding and a code interpreter in supported workflows; those features must be enabled and assessed for your security and compliance requirements. AWS redacts internal reasoning content in responses even though the tokens may be billable. AWS reasoning documentation.

PRACTICAL USE CASES

Where Nova 2 Lite is useful—and where another model may be better.

DOCUMENT AUTOMATION

Forms, PDFs and scanned pages

Extract targeted fields and summarize text-plus-image documents. Specify an output format, retain the source page and review low-confidence extraction before downstream actions.

CUSTOMER SUPPORT

Policy-aware response drafts

Ground replies in current knowledge-base passages, ask for citations and test policy conflicts. Human review remains important for high-stakes support decisions.

CODING & AGENTS

Task planning and tool use

Draft code, propose multi-step plans and supply text instructions to external tools. Use permissions, tool-call validation and audit logging in production.

A useful architectural pattern is a two-stage document pipeline: have Nova 2 Lite extract image/text metadata at lower cost, then route only ambiguous spatial relationships to a more specialized reasoning model. AWS documented this approach in June 2026 using scanned yearbook pages. It is evidence of a particular pipeline—not a universal accuracy or savings claim. Read the AWS case study.

FREQUENTLY ASKED QUESTIONS

Amazon Nova 2 Lite FAQ.

What is Amazon Nova 2 Lite?

Amazon Nova 2 Lite is a multimodal, text-output reasoning model available through Amazon Bedrock. It handles text, images, documents and video for automation, analysis and agentic workloads.

How much does Amazon Nova 2 Lite cost?

SXF's tracked Standard reference rates are $0.30 per million input tokens and $2.50 per million output tokens. Actual AWS prices vary by routing, Region, service tier and caching, so confirm the applicable Amazon Bedrock pricing table.

What is the Amazon Nova 2 Lite model ID?

The base model ID is amazon.nova-2-lite-v1:0. Amazon Bedrock also offers inference profile IDs including global.amazon.nova-2-lite-v1:0 and us.amazon.nova-2-lite-v1:0, depending on regional availability.

What are the context window and maximum output?

AWS lists 1 million context tokens and 64K maximum output tokens for Amazon Nova 2 Lite on its Bedrock model card. Application settings and service constraints may impose lower effective limits.

Does Nova 2 Lite understand video and audio?

Nova 2 Lite analyzes video visually along with text, images and documents, but does not provide general audio-track transcription or native audio output. Use a speech model for audio-specific tasks.

Does Amazon Nova 2 Lite support reasoning?

Yes. Extended thinking is disabled by default and can be enabled with low, medium or high reasoning effort. Reasoning tokens may be billed even when reasoning content is redacted.

Can I call Amazon Nova 2 Lite with Python?

Yes. Use boto3 with the Amazon Bedrock Runtime Converse API, your AWS credentials and an available model inference profile. The Python example above provides a minimal request.

Is Nova 2 Lite better than Nova 1 Lite?

Nova 2 Lite expands the context window from 300K to 1M tokens, adds extended thinking and built-in tools, and increases the documented output capacity. Whether it performs better for your application should be determined with a representative test set.
