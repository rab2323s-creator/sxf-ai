MODEL QUICK ANSWER

What is DeepSeek V4 Pro?

DeepSeek V4 Pro is DeepSeek's higher-capability text-only reasoning, coding and agent model, released for general availability on August 13, 2026. It offers a 1,048,576-token context window, a maximum output of 393,216 tokens, configurable thinking effort, tool calling and compatible Chat Completions / Responses / Anthropic-style APIs. The exact model ID is deepseek-v4-pro.

The key distinction from DeepSeek V4.1 Flash is model positioning: V4 Pro prioritizes difficult text reasoning and coding; Flash emphasizes throughput, lower API cost and image input. DeepSeek's pricing uses peak and off-peak rates, with much cheaper cached-input tokens. It is not accurate to display one permanent flat token price.

DEEPSEEK API PRICING

DeepSeek V4 Pro pricing: peak vs off-peak and cache hits.

DeepSeek charges for uncached input tokens, cached input tokens and generated output tokens. All six figures below are in USD per one million tokens. Prices are time-dependent and the provider can update them; do not use a fixed-price calculator that ignores UTC billing windows.

OFF-PEAK INPUT · CACHE MISS

$0.66 / 1M

Uncached text input during off-peak hours. Used for fresh prompts or nonmatching cached prefixes.

OFF-PEAK INPUT · CACHE HIT

$0.022 / 1M

Charged only when DeepSeek's cache actually reuses a persisted prompt prefix.

OFF-PEAK OUTPUT

$1.98 / 1M

Generated output tokens. Include any billed reasoning output in your overall usage estimates.

PEAK INPUT · CACHE MISS

$1.32 / 1M

New input during peak hours; double the off-peak uncached rate.

PEAK INPUT · CACHE HIT

$0.044 / 1M

Cached-prefix input during peak hours, when the cache-hit condition is met.

PEAK OUTPUT

$3.96 / 1M

Generated output during peak hours; double the off-peak output rate.

Peak times: 01:00–04:00 UTC and 06:00–10:00 UTC, Monday through Friday. Other times are off-peak; check DeepSeek's current holiday exceptions and service notice. Off-peak token prices are one-half of peak prices across all three billing dimensions.

Concrete cost example: a request with 100,000 uncached input tokens and 20,000 output tokens is approximately $0.1056 off-peak (0.1 × $0.66 + 0.02 × $1.98), or $0.2112 at peak (0.1 × $1.32 + 0.02 × $3.96). If all 100,000 input tokens qualify as cache hits, the corresponding off-peak estimate is $0.0418. These are arithmetic examples, not a fixed price for every request or a latency guarantee.

See the official DeepSeek token rate card. SXF intentionally excludes this model from its flat-price calculator because a single input/output pair would misstate real billing.

THINKING AND REASONING

DeepSeek V4 Pro thinking mode: none, low, high and max.

DeepSeek supports non-thinking and thinking modes. Thinking is on by default, with high effort. Developers can choose reasoning_effort: "none", "low", "high" or "max". The provider maps compatibility aliases such as medium to high, so a label does not necessarily represent a distinct compute tier.

NONE

Thinking disabled

Use for straightforward extraction, summarization or formatting where additional deliberation is unnecessary.

LOW

Light deliberation

Consider for simple coding corrections, routine instructions or agent steps where throughput matters.

HIGH

Default effort

Balances more deliberate text reasoning with normal agent workflows. Evaluate token usage and answer quality on your own tasks.

MAX

Deepest supported tier

Use selectively for challenging repository analysis, mathematics or multi-step reasoning. It can increase billed output and latency.

Important parameter behavior: in thinking mode, DeepSeek documents that temperature, presence_penalty and frequency_penalty do not take effect. top_p is constrained to 0.95–1.0. For tool-using conversations, handling of reasoning_content differs from ordinary text-only multi-turn chats; follow the provider's thinking-mode state guidance.

API QUICKSTART

How to call the DeepSeek V4 Pro API.

The provider uses the OpenAI-compatible base URL https://api.deepseek.com. Send a POST /chat/completions request with a DeepSeek API key, the exact deepseek-v4-pro identifier and an appropriate reasoning_effort. The following is a minimal text-only call; keep API keys on the server.

curl https://api.deepseek.com/chat/completions \
  -H "Authorization: Bearer $DEEPSEEK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-pro",
    "messages": [
      {"role": "system", "content": "Give concise, verifiable answers."},
      {"role": "user", "content": "Explain three trade-offs in a database migration plan."}
    ],
    "reasoning_effort": "high",
    "thinking": {"type": "enabled"},
    "max_tokens": 2048
  }'
01

Call the correct model: use deepseek-v4-pro. deepseek-flash points to the separate V4.1 Flash model and its own price schedule.

02

Control reasoning: use reasoning_effort to choose low, high or max; set thinking.type if an explicit enabled/disabled toggle is useful in your client.

03

Budget output: set max_tokens within the documented 384K ceiling, and inspect finish_reason if an output gets truncated.

04

Capture real cost: inspect usage and its prompt_cache_hit_tokens / prompt_cache_miss_tokens breakdown, and apply the billing window in UTC.

DeepSeek also provides OpenAI Responses API compatibility and an OpenAI/Anthropic SDK quickstart. Validate current parameter support in the endpoint you actually call.

REPOSITORY CODING

RESPONSES API

Multi-step agent messages

DeepSeek supports the Responses API format, with model-produced tool calls and application-supplied tool results; its documented endpoint is stateless.

Conversation state matters: when tool calls are present, DeepSeek's thinking documentation describes how to carry forward previous reasoning_content where required. For mid-conversation insertion of tool calls, its documentation advises Responses or Anthropic API rather than Chat Completions. See Tool Calls and JSON Output.

CACHING AND COST CONTROL

How DeepSeek V4 Pro context caching reduces input cost.

DeepSeek enables prefix-based context caching by default. When a previous prompt prefix has been persisted and the next request matches it, qualifying input tokens use the cache-hit rate instead of the uncached input price. A shared system prompt or stable document prefix is a candidate for reuse, but cache hits are not guaranteed.

01

Put reusable context first: keep stable system instructions and shared documents at the beginning of repeated requests, where matching is possible.

02

Inspect reported cache usage: compare prompt_cache_hit_tokens with prompt_cache_miss_tokens to see how much reuse occurred.

03

Separate cache from schedule: off-peak cache hits cost $0.022 per million tokens; peak cache hits cost $0.044 per million. Peak/off-peak is a separate multiplier.

04

Measure production behavior: changing prefixes, cache persistence and workload patterns can reduce hit rates. Do not treat maximum theoretical savings as an observed benchmark.

Reference: DeepSeek context caching documentation.

MODEL COMPARISON

DeepSeek V4 Pro vs V4.1 Flash: cost, vision and context.

HIGHER-CAPABILITY TEXT MODEL

DeepSeek V4 Pro

Official version DeepSeek-V4-Pro-0813. Text input and output; 1M context; 384K output; off-peak uncached input $0.66/1M and output $1.98/1M. Best evaluated on difficult text reasoning, code and agents.

LOWER-COST MULTIMODAL

DeepSeek V4.1 Flash

Official API ID deepseek-flash. Supports image input (not image generation), with the same listed 1M context / 384K max output. Off-peak uncached input $0.15/1M and output $0.60/1M.

Practical choice: use V4 Pro when sophisticated reasoning or long multi-tool workflows justify a higher token budget. Choose V4.1 Flash for image questions, inexpensive high-volume workloads or routine agent requests. Both need evaluation on your own data; this comparison does not claim a universal quality winner.

DeepSeek's official side-by-side feature table is the source for capabilities and prices. For other providers, explore the SXF comparison hub or the model pricing index.

DEEPSEEK V4 PRO FAQ

Frequently asked questions about API access, reasoning and pricing.

01

What is DeepSeek V4 Pro? DeepSeek V4 Pro is DeepSeek's higher-capability text-only model for long-context reasoning, coding and tool-using agents. The GA version is available via the DeepSeek API using the model ID deepseek-v4-pro.

02

Is DeepSeek V4 Pro still available in the API? Yes. DeepSeek's September 10, 2026 change log says it will continue V4 Pro API service after September 14, reversing the earlier phase-out plan. Always check the official model list for current status.

03

What is the DeepSeek V4 Pro model ID? Use deepseek-v4-pro with the DeepSeek Chat Completions, Responses or supported Anthropic-compatible API. Do not substitute deepseek-flash, which serves V4.1 Flash.

04

What is DeepSeek V4 Pro's context window? The official model registry lists a 1,048,576-token context window, often described as 1M tokens. This is a total context budget, not a promise that every prompt length delivers the same performance.

05

What is the maximum DeepSeek V4 Pro output length? The published maximum is 393,216 tokens (384K). The API's default completion limit is much smaller: 8K without thinking, 64K with thinking, or 128K with max reasoning effort unless max_tokens is set.

06

How much does DeepSeek V4 Pro cost per million tokens? Off-peak rates are $0.66 for uncached input, $0.022 for cache-hit input and $1.98 for output. Peak rates are $1.32 for uncached input, $0.044 for cache-hit input and $3.96 for output, all per million tokens.

07

When are DeepSeek V4 Pro peak hours? Official peak windows are 01:00–04:00 and 06:00–10:00 UTC, Monday through Friday; other hours are off-peak. The catalog also notes Chinese public-holiday exceptions, so check the current provider schedule.

08

What reasoning levels does DeepSeek V4 Pro support? It supports none (thinking disabled), low, high and max. Thinking is enabled by default at high effort. The Chat Completions API uses reasoning_effort and optionally thinking.type.

09

Can DeepSeek V4 Pro read images? No. DeepSeek lists V4 Pro as text-input/text-output only. DeepSeek V4.1 Flash supports image input, so choose Flash if your workflow needs direct visual understanding.

10

Does DeepSeek V4 Pro support tools and JSON? Yes. Its official model table lists tool calls, JSON output, Chat Prefix Completion beta, FIM beta, the Responses API and Anthropic API compatibility. Tool execution is performed by your application, not automatically by the model.

11

How does DeepSeek V4 Pro context caching work? DeepSeek's prefix context caching is enabled by default. When a previously persisted prefix matches, those input tokens are billed at the cache-hit rate. Cache reuse is conditional, not guaranteed for every repeated prompt.

12

DeepSeek V4 Pro vs DeepSeek V4.1 Flash: which should I choose? V4 Pro is the higher-capability text-only option for demanding reasoning, coding and multi-tool tasks; V4.1 Flash is lower-priced, optimized for throughput and supports image input. Both have a 1M-token context window in the official registry.

13

Does DeepSeek V4 Pro have published benchmark results? DeepSeek's August 2026 release supplies named benchmark results for its GA model. SXF also displays independent evaluator results with benchmark names and configurations; do not treat different scores as a single universal quality ranking.

14

How do I call DeepSeek V4 Pro using the OpenAI SDK? Use base_url https://api.deepseek.com, your DeepSeek API key and model deepseek-v4-pro. Choose an optional reasoning_effort such as high, send a messages array and read the final response content and token usage.
