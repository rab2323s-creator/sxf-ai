MODEL OVERVIEW

What is Runway Gen-4.5?

Runway Gen-4.5 is a video-generation model that turns written directions into moving scenes or animates a supplied image. The model is designed for creators who want to direct the subject, camera movement and timing of short shots instead of relying on an undirected animation. It supports both text-to-video and image-to-video workflows in Runway's web app and developer tools.

Quick answer: Runway documents 2–10-second clips, standard 720p output, 24 or 25 fps in the creator interface, and a base generation rate of 12 credits per second. The Runway Dev API model identifier is gen4.5. Video generation is billed by output duration, not language-model input/output tokens.

MODEL PRICING

Runway Gen-4.5 pricing: credits and cost per video.

Runway Dev charges 12 credits per second for Gen-4.5. The developer portal sells credits at $0.01 each, making the base API equivalent $0.12 per second. The catalog's $7.20 per generated minute is only a unit conversion: a normal Gen-4.5 generation is a 2–10-second clip, not a one-minute output.

VIDEO GENERATION MODES

Runway Gen-4.5 text-to-video vs image-to-video.

TEXT TO VIDEO

Describe the entire shot

Provide the subject, environment, action, framing, lighting and camera motion in words. Start here for exploring fresh concepts, scene designs and cinematic establishing shots without a reference image.

Example prompt: A wide shot of a tram moving through a rainy neon-lit city at dusk. The camera tracks beside it as reflections glide across the wet pavement, then gently pushes toward the driver.

IMAGE TO VIDEO

Animate a chosen first frame

Upload or pass a still image to anchor the subject and composition. Then focus the written prompt on motion and timing: what changes, how the subject moves and how the camera behaves. This is useful for products, character continuity and art-directed shots.

Example motion prompt: The camera makes a slow clockwise orbit around the bottle. Condensation droplets roll down the glass as the background lights softly drift out of focus.

Prompting distinction: text-to-video needs visual and motion detail; image-to-video typically needs much less re-description of the supplied image and more instruction about movement. Runway's text-to-video guide and image-to-video guide explain both approaches.

PROMPT ENGINEERING

How to write better Gen-4.5 prompts.

01

Specify visible actions. Replace vague goals like “a dramatic video” with concrete subject movements, physical interactions and environmental changes. In text-to-video, establish the shot first; in image-to-video, use the supplied frame as the starting point.

02

Direct the camera. Use film terms such as locked camera, dolly-in, orbit, overhead tracking or handheld movement, and specify direction and pacing. Avoid stacking several conflicting movements into a short clip.

03

Give events a sequence. For more complex action, describe a clear beginning, transition and end. A 10-second shot has more room for multiple beats than a 2-second shot.

04

Iterate one variable at a time. Keep the subject and framing fixed while testing a different camera path or motion speed; this makes failures easier to diagnose and helps you compare outputs.

05

Use a clean reference frame. Image-to-video depends heavily on the input image's framing and subject clarity. Describe the desired animation directly instead of trying to rewrite the appearance of an already-defined scene.

These are practical workflow recommendations grounded in Runway's Gen-4.5 prompting academy and camera-direction examples. Results vary by scene, prompt and input frame.

RUNWAY DEVELOPER API

How to use Gen-4.5 through the API.

Runway's documented SDK and API use the exact model identifier gen4.5. Create an image-to-video task with a promptImage and a promptText; omit the image for text-only video generation. The generation endpoint creates an asynchronous task: collect the task ID and retrieve the completed output using the API or the SDK's waiting helper.

01

Set up Runway Dev: create an API project and store your secret in RUNWAYML_API_SECRET, never in browser-side source code.

02

Pick the mode: use model: "gen4.5", promptText, duration and ratio. For image-to-video, add promptImage with an accepted image URL or upload reference.

03

Submit and monitor: POST to /v1/image_to_video, receive a task ID, and fetch the result when the task completes. Handle failures and retries in production rather than assuming synchronous output.

Minimal text-to-video request:

curl -X POST https://api.dev.runwayml.com/v1/image_to_video \
  -H "Authorization: Bearer $RUNWAYML_API_SECRET" \
  -H "X-Runway-Version: 2024-11-06" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gen4.5",
    "promptText": "A wide shot of clouds crossing snowy peaks. Slow dolly forward.",
    "ratio": "1280:720",
    "duration": 5
  }'

For image-to-video, supply a valid promptImage field as well. The request structure is based on Runway's official API quickstart. Validate output sizes, account access and current API-version requirements before deploying.

ALTERNATIVES AND TRADE-OFFS

Gen-4.5 vs Gen-4 Turbo: cost and workflow.

RUNWAY GEN-4.5

12 credits per second

Choose when you want to test Runway's newer prompt-adherence and complex motion capabilities, with both text-to-video and image-to-video options.

RUNWAY GEN-4 TURBO

5 credits per second

A lower-cost Runway alternative for rapid image-to-video iterations and simpler creative experiments. Gen-4 Turbo is not a direct substitute for all Gen-4.5 modes; compare each mode and use case before selecting.

At 5 seconds, base Runway Dev pricing works out to approximately $0.60 for Gen-4.5 or $0.25 for Gen-4 Turbo. This is a price comparison, not a claim about measured visual quality. For other vendors, explore the Kling 3.0 model reference or the SXF model comparison hub.

COMMON QUESTIONS

Runway Gen-4.5 FAQs.

01

What is Runway Gen-4.5? Runway Gen-4.5 is Runway's video-generation model for making short clips from text prompts or a reference image plus a motion prompt. Its strengths include camera direction, multi-action prompts, and visual continuity.

02

How much does Runway Gen-4.5 cost? Runway Dev lists 12 credits per generated second. At $0.01 per developer API credit, a 5-second clip costs 60 credits ($0.60), and a 10-second clip costs 120 credits ($1.20), before taxes or optional output-format charges. Creative-app plan billing is separate.

03

What is the Runway Gen-4.5 API model ID? Use gen4.5 in Runway's API or SDK. The documented image-to-video endpoint also accepts text-to-video requests when promptImage is omitted.

04

Does Gen-4.5 support text-to-video and image-to-video? Yes. Text-to-video accepts a written scene and motion description. Image-to-video uses an input still image to define appearance and composition, with text describing how the image should animate.

05

What video durations and resolution does Gen-4.5 support? Runway's creator documentation lists 2 to 10 seconds, a standard 720p output and 24 or 25 frames per second in the web app. Aspect-ratio options depend on the mode.

06

What aspect ratios are available for Gen-4.5? Runway lists 16:9 and 9:16 for text-to-video, while image-to-video supports landscape, portrait, square and widescreen formats, including 16:9, 9:16, 1:1, 4:3, 3:4 and 21:9.

07

How should I write a Gen-4.5 prompt? For text-to-video, describe the subject, setting, action, camera movement and desired timing. For image-to-video, let the input still establish the visual scene and emphasize movement and temporal changes in the prompt.

08

Is Runway Gen-4.5 cheaper than Gen-4 Turbo? No. Runway Dev lists Gen-4.5 at 12 credits per second and Gen-4 Turbo at 5 credits per second. Gen-4 Turbo is the lower-cost choice for iterations; output quality should be judged on your own test prompts.

09

Can I generate a 60-second video with one Gen-4.5 request? Not through the standard 2–10-second clip-generation modes documented for Gen-4.5. Longer sequences require producing and editing or combining shorter shots.

10

Can I export ProRes or HDR with Gen-4.5? Runway documents optional professional output formats. ProRes or PNG sequence adds 5 credits per second; HDR or other 10-bit formats have a separate surcharge. Availability and pricing can depend on plan, output dimensions and format.

CAVEATS

What the source record does not assume.

01

Official Runway Dev API model ID is gen4.5, usable for both text-to-video and image-to-video requests.

02

Runway developer price: 12 credits per generated second and $0.01 per purchased API credit, equivalent to $0.12 per second or $7.20 per minute before sales tax. The catalog displays the one-minute equivalent, NOT a charge for a fixed video.

03

04
