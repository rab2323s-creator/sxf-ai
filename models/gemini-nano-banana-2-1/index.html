MODEL OVERVIEW

What is Nano Banana 2.1?

Nano Banana 2.1 is Google's high-efficiency model for AI image generation and conversational image editing. Its exact Gemini API ID is gemini-nano-banana-2.1. Google calls it the newer production workhorse compared with Nano Banana 2 (Gemini 3.1 Flash Image), with improved realism, text rendering, prompt adherence, multi-turn character consistency and Google Search grounding. It is the more cost-efficient counterpart to Nano Banana Pro.

Quick answer: output at 1K, 2K or 4K (1K default), work with up to 14 reference images, configure thinking (minimal, medium, high), and ground requests with Google Web and Image Search. Official Standard API image-output estimates start at $0.0336 for 1K. Input and thinking costs are separate. Google documents these capabilities in its model card.

GEMINI API PRICING

Nano Banana 2.1 price per image: Standard, Batch and hidden costs.

Google's paid Standard API rate for generated image output is $30 per one million image tokens, equivalent to its published estimates below. Input text/images/video are $1.50 per million tokens, while text and thinking output are $7.50 per million tokens. Those are three distinct meters; never use the image-output rate to price textual output.

BATCH · 4K

$0.0567 / image

Published Batch output estimate at 4K, with the same caveat for separate non-image billing.

Production budget example: 100 Standard 1K image outputs cost about $3.36 in image-output fees; 100 Standard 4K outputs cost about $11.30. For Batch, comparable output fees are about $1.68 and $5.67. These are not complete request bills: prompts, image/video references, text/thinking output and chargeable searches may increase totals.

Grounding rate: Google lists 5,000 free Web/Image Search grounding requests monthly, shared across Gemini 3 and newer models, followed by $14 per 1,000 requests. The API free tier for the model itself is not available. Check the latest Google Gemini API pricing schedule before production cost estimates.

IMAGE CREATION AND EDITING

Nano Banana 2.1 text-to-image and conversational image editing.

TEXT TO IMAGE

Turn a prompt into a scene

Specify the subject, composition, camera angle, materials, lighting, aspect ratio and any text that must appear. Try multiple alternatives at 1K, then use 2K or 4K for the final layout.

Example prompt: “Create a clean 4:5 product photograph of a matte black travel bottle on sandstone, side-lit at golden hour. Minimal pale background. Label text exactly ‘NORTH’. Realistic contact shadow.”

CONVERSATIONAL EDITING

Make precise follow-up changes

Provide an input image, request a new background, remove a distracting object or change clothing while preserving identity. Multi-turn revisions work best when you distinguish new changes from elements that must remain.

Example edit: “Keep the product shape, brand color and label unchanged. Replace the desk with a sunny kitchen counter. Preserve camera angle and perspective.”

OBJECT AND CHARACTER REFERENCES

Combine multiple image sources

Supply references for products, people and style; explicitly assign roles by image number. Google lists up to 14 references overall, with distinct object/character fidelity guidance.

Example: “Place the chair from image 1 in the room from image 2, apply the texture in image 3, and retain the seated person's clothing from image 4.”

DESIGN WITH TEXT

Layouts, localization and charts

Google highlights improved text rendering and infographic layout. Use exact quoted text and verify letters, translations, axes, numbers and any legal claims before publishing.

These example prompts are editorial illustrations of the model's documented workflows, not provider-certified quality benchmarks. Read Google's multi-turn editing and multi-image guide for input formatting.

GEMINI DEVELOPER API

How to use Nano Banana 2.1: REST API example.

Send requests to Google's Gemini Interactions API with model ID gemini-nano-banana-2.1. The example below asks for a 2K landscape image with the documented response_format object. Configure your GEMINI_API_KEY on the server; do not expose it in client-side JavaScript.

curl -s -X POST \
  "https://generativelanguage.googleapis.com/v1beta/interactions" \
  -H "x-goog-api-key: $GEMINI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-nano-banana-2.1",
    "input": "A photorealistic editorial kitchen scene with a copper kettle, soft morning light and natural shadows.",
    "response_format": {
      "type": "image",
      "aspect_ratio": "16:9",
      "image_size": "2K"
    }
  }'
01

Image generation: request gemini-nano-banana-2.1, set image size and aspect ratio, and read the image data returned by the Interactions API or SDK.

02

Image editing: send image and text input blocks together to request an edit. Preserve the previous interaction context for follow-up edits when appropriate.

03

Google Search grounding: optionally add "tools": [{"type": "google_search", "search_types": ["web_search", "image_search"]}]. Budget for any billable search usage and verify licensing of source content.

04

Mixed output: when requesting images plus explanatory text, process all content blocks. Do not assume every response uses only one image or that generated text is always correct.

Copy the current request shape and SDK patterns from the Google Interactions API image-generation examples. The older generateContent request and response formats differ and should not be mixed into the same example.

PRODUCTION PROMPTING

Prompts and workflow tips for better Nano Banana 2.1 results.

01

Write a complete creative brief: start with subject, environment, framing, materials and lighting, then specify what the image is for.

02

Give visible text explicitly: quote the exact headline, label or call-to-action. Recheck spelling, brand marks and font consistency.

03

Assign roles to references: say which image supplies the product, person, color palette and scene. Avoid relying on the model to infer source priority.

04

Separate edits from invariants: state what should change and what must remain fixed (identity, product geometry, original logo, text placement).

05

Test 1K before 4K: choose size according to delivery needs and estimate both image-output and non-image costs. Large size is not a substitute for good composition.

06

Review data-backed visuals: audit numerical charts, factual map details, third-party marks and any grounded search-derived material.

These are practical editorial recommendations, not guarantees of precise reproduction. Google's model card reports improvements to text layout and panoramic tiling; production results still depend on prompts and reference quality.

NANO BANANA 2.1 FAQ

Questions about prices, 4K images, API and editing.

01

What is Nano Banana 2.1? Nano Banana 2.1 is Google's high-efficiency Gemini image-generation and conversational editing model, an upgrade from Gemini 3.1 Flash Image (Nano Banana 2). It targets faster, more affordable production with stronger text rendering, multi-turn consistency and 1K–4K images.

02

What is the Nano Banana 2.1 API model ID? Use gemini-nano-banana-2.1 in the Gemini Interactions API or compatible Google GenAI SDK. It is different from gemini-3.1-flash-image (Nano Banana 2) and gemini-3-pro-image (Nano Banana Pro).

03

How much does Nano Banana 2.1 cost per generated image? Google's Standard paid API output estimates are $0.0336 per 1K image, $0.0504 per 2K image and $0.113 per 4K image. Input tokens, text/thinking output and optional Google Search grounding are charged separately.

04

How much does Nano Banana 2.1 Batch cost? Google lists Batch image-output estimates of $0.0168 per 1K image, $0.0252 per 2K image and $0.0567 per 4K image. Batch is asynchronous, and non-image request costs still apply.

05

Is Nano Banana 2.1 free in the Gemini API? The official Gemini Nano Banana 2.1 pricing table lists no free API tier. Access through Google AI Studio or a consumer app follows separate availability and usage conditions.

06

Does Nano Banana 2.1 generate 4K images? Yes. It supports 1K (default), 2K and 4K image-output tiers. Google documents a 4096×4096 4K square and 5504×3072 4K 16:9 output, as well as wider panoramic ratios.

07

How many reference images can Nano Banana 2.1 use? Google documents up to 14 input reference images, with fidelity guidance for up to 10 objects and consistency across up to 4 characters in a workflow. Those are not guarantees of perfect identity reproduction.

08

Can Nano Banana 2.1 edit existing images? Yes. Supply image content and an edit request through the Gemini API, then make additional changes in a multi-turn workflow. Explicitly state what to alter and which identities, shapes, colors or words to preserve.

09

Which thinking levels does Nano Banana 2.1 support? It supports minimal, medium and high thinking levels, with medium as the documented default. Greater thinking can increase latency or token usage and does not guarantee a flawless output.

10

Does Nano Banana 2.1 support Google Image Search grounding? Yes. Google documents web_search and image_search as search_types for its google_search tool, allowing the model to incorporate current web and image context. Grounded visual facts and licensing must still be reviewed.

11

What is the difference between Nano Banana 2, 2.1 and Pro? Nano Banana 2.1 is Google's recommended newer high-efficiency production model; Nano Banana 2 is the previous Gemini 3.1 Flash Image endpoint; Nano Banana Pro uses gemini-3-pro-image for more demanding professional visual tasks. Each has different pricing and capabilities.

12

What inputs can Nano Banana 2.1 accept? The official model card lists text, images, video and PDF input, with text and image output. A 131,072-token input limit and 32,768-token output limit are published, but those limits are not image pixel dimensions.

13

Can I use Nano Banana 2.1 for logos, labels and infographics? It supports advanced text rendering, diagram layout and branded image editing, but generated spelling, trademarks, data labels and chart values must be checked manually before production use.

14

Does Nano Banana 2.1 watermark images? Google says Nano Banana generated images include an invisible SynthID watermark. The watermark does not replace rights clearance, image review or any required AI-content disclosure.
