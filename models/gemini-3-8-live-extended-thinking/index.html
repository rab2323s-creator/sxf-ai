QUICK ANSWER

What is Gemini 3.8 Live Extended Thinking?

Gemini 3.8 Live Extended Thinking is Google's high-reasoning, real-time voice model for conversations that need more than quick spoken answers. It streams audio while working through multi-step requests and executing asynchronous functions in the background. Developers access it through the Gemini Live API using the model ID gemini-3.8-live-extended-thinking.

The main distinction is background reasoning without treating every spoken pause as the end of a request. A voice agent can acknowledge the user, call an external tool, and continue speaking as results arrive. Google's model card lists a 131,072-token input limit, 65,536-token output limit, text/image/audio/video input and text/audio output.

CORE CAPABILITIES

How background reasoning changes a voice agent.

CONTINUOUS SPEECH

Audio while work continues

Intermediate spoken updates can keep a user informed while the model reasons or waits for an external service, instead of forcing a silent pause for every tool call.

THINKING LEVELS

Low, medium or high

Configure reasoning depth with thinking_config and thinking_level. The minimal level is not supported for this model.

TOOL EXECUTION

Async-only function calling

Declare functions with behavior: NON_BLOCKING. Synchronous blocking declarations are not supported, which matters when migrating an existing Live integration.

SESSION LIFECYCLE

Watch interaction status

An audio message ending with turnComplete does not always mean the full job is finished. IN_PROGRESS and IDLE identify active background work and true completion.

Google lists Standard paid API rates in USD. A voice session can combine audio, text, and image/video usage, so a text-only calculator does not reflect the whole bill.

MODEL COMPARISON

Gemini 3.8 Live vs Live Extended Thinking: which should you use?

FASTER DIRECT CONVERSATIONS

Gemini 3.8 Live

Better suited to quick voice commands, immediate back-and-forth and simpler tool flows. It does not accept a thinking_level setting and supports both blocking and non-blocking tools.

COMPLEX MULTI-STEP TASKS

Gemini 3.8 Live Extended Thinking

Designed for spoken assistants that plan, research or troubleshoot across several tools. It offers low/medium/high background reasoning, async-only tools and interaction_status-based completion.

Practical choice: start with the standard Live endpoint for low-latency dialogue. Choose Extended Thinking when the quality of multi-step reasoning and non-blocking background work matters more than the simplest turn-taking flow.

API INTEGRATION

How to use Gemini 3.8 Live Extended Thinking in the Live API.

01

Select the endpoint. Connect through the Gemini Live API using gemini-3.8-live-extended-thinking, not gemini-3.8-live. This is a streaming, bidirectional session rather than an ordinary one-shot text request.

02

Configure background reasoning. Set thinking_config to low, medium or high; declare any callable functions with NON_BLOCKING behavior. Google documents that blocking functions produce an error for Extended Thinking.

03

Handle the full interaction lifecycle. When your client receives interactionStatus: IN_PROGRESS, keep the session active even if turnComplete: true arrives for an interim utterance. Treat interactionStatus: IDLE as completion of the background task.

04

Test streaming and interruption. Google states that send_client_content works throughout the session with explicit user/model roles, and sending turn_complete=true interrupts active generation. Proactive audio is permanently enabled.

For complete SDK and WebSocket examples, see Google's Thinking in the Live API guide and Live API capabilities documentation.

Google lists Search grounding and asynchronous function calling as supported. Developers should not assume standard text API features automatically carry over to Live audio sessions.

FAQ

Gemini 3.8 Live Extended Thinking FAQ.

01

What is Gemini 3.8 Live Extended Thinking? It is Google's high-reasoning Live API audio-to-audio model for real-time voice agents that plan multi-step work and call asynchronous tools while continuing the conversation.

02

What is the exact API model ID? Use gemini-3.8-live-extended-thinking in the Gemini Live API. It is a separate endpoint from gemini-3.8-live.

03

What is its context window? Google publishes a 131,072-token input limit and a 65,536-token output limit.

04

How much does Gemini 3.8 Live Extended Thinking cost? Google's paid Standard rates are $0.75 per million text input tokens and $4.50 per million text output tokens; audio costs $3 input and $12 output per million audio tokens. Image/video input is $1 per million tokens. The output rates include thinking tokens.

05

Does it support background thinking and async tools? Yes. Set thinking_level to low, medium or high; minimal is unsupported. Function declarations must use NON_BLOCKING behavior.

06

How is Extended Thinking different from Gemini 3.8 Live? Gemini 3.8 Live prioritizes low-latency direct dialogue. Extended Thinking adds configurable background reasoning and requires interaction_status to decide whether the entire request has finished.

07

Does turnComplete mean the session is idle? Not necessarily. During background reasoning an utterance may finish while interaction_status remains IN_PROGRESS; wait for IDLE before treating the full task as complete.

08

Does the model support caching, Batch API or structured outputs? No. Google's model card lists caching, Batch API and structured outputs as unsupported for this endpoint.
