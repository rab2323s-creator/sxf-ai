DIRECT ANSWER / FEBRUARY 2026 VERSION

What is Voxtral Mini Transcribe 2?

Voxtral Mini Transcribe 2 (also called Voxtral Mini Transcribe V2 or 2.0) is Mistral AI's file-based speech-to-text model, released on February 4, 2026. Its pinned API ID is voxtral-mini-2602. It transcribes recordings rather than chatting with them and, in its original interface, supports speaker diarization, word-level timestamps and custom vocabulary across 13 languages.

Historical direct API pricing: $0.003 per audio minute, equivalent to $0.18 per recorded hour. Mistral separately lists a $0.0003/min Batch tier for eligible asynchronous jobs. These are transcription API charges, not the labor cost of reviewing and correcting transcripts. The model is a Premier hosted service; do not confuse it with the downloadable, Apache-2.0 Voxtral Realtime 2 model.

Version and migration notice — verified November 7, 2026

Mistral introduced Voxtral 3 on October 20, 2026 and now lists this 2026-02 edition under deprecated models. The replacement for voxtral-mini-2602 is voxtral-mini-transcribe-3-0. This page remains the dedicated reference for version 2 and its documented behavior; it does not promise ongoing API access or treat the V2 price as the current price for V3. See what breaks when migrating to Voxtral 3 or Mistral's official migration checklist.

Speaker-labeled transcriptions help distinguish participants in interviews, meeting notes and call recordings. Speaker IDs do not prove a person's identity.

TIMING

Historical V2 documentation supports timestamp_granularities values word and segment. In V3, word is removed.

CUSTOM TERMS

Up to 100 bias entries

V2's context_bias can guide spelling of names, products and technical vocabulary. Mistral notes strongest optimization for English; test other languages.

RECORDING LIMIT

Up to 3 hours

Mistral's archived V2 audio documentation describes files up to three hours per request. Split longer recordings and preserve segment offsets across chunks.

Supported V2 languages: English, Chinese, Hindi, Spanish, Arabic, French, Portuguese, Russian, German, Japanese, Korean, Italian and Dutch. The 13-language list comes from Mistral's archived Voxtral 2 documentation, not from a newly measured SXF language-quality study. A language being supported is not a guarantee of equal word error rate across accents, code-switching or noisy recordings.

Unlike language-model pages, the original V2 model card does not publish a comparable token context window or a text-generation output cap. The 3-hour recording guidance should not be converted into an invented token-context number.

VERSION-PINNED DEVELOPER EXAMPLES

Voxtral Mini Transcribe 2 API: Python SDK and cURL transcription.

V2 historically uses POST https://api.mistral.ai/v1/audio/transcriptions and pinned model ID voxtral-mini-2602. Do not assume voxtral-mini-latest still points to V2: the migration guide names new explicit V3 aliases. These examples are documentation-backed integration templates; availability of the deprecated V2 ID must be confirmed on your Mistral workspace.

Python: transcribe a local WAV file using the Mistral SDK

import os
from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

with open("meeting.wav", "rb") as audio:
    result = client.audio.transcriptions.complete(
        model="voxtral-mini-2602",  # Pin V2; check access first
        file={"content": audio, "file_name": "meeting.wav"},
    )

print(result.text)

Install the official mistralai package and store the key server-side. Validate MIME type, duration, access permissions, file retention and response fields before writing the transcript to a user-facing system.

cURL: request segment timestamps and speaker labels

curl "https://api.mistral.ai/v1/audio/transcriptions" \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -F "model=voxtral-mini-2602" \
  -F "file=@meeting.wav" \
  -F "timestamp_granularities=segment" \
  -F "diarize=true"

Mistral's archived V2 documentation also allows timestamp_granularities=word for word-level timing and context_bias for terms. Not every option is valid in every combination: the historical docs warn against combining an explicit language with timestamps. Always validate the actual response schema. The archived V2 SDK guide and API specification document these request fields.

OUTPUT INTERPRETATION

How word timestamps, speaker diarization and context biasing work in Voxtral 2.

Word timestamps associate recognized words with times in the recording and can support subtitle editing, searching recordings and audit review. Speaker diarization groups speech by speaker, but a label such as speaker_1 is not verified identity. Context biasing supplies expected spelling of names and acronyms without changing the underlying audio.

Common transcription requirements and the right test
RequirementV2 setting / approachCritical limitation
Meeting speaker turnsdiarize=true with segment outputOverlapping or similar voices need human checks
Subtitle timingtimestamp_granularities=word in V2V3 does not accept word; migrate the subtitle pipeline
Brand/product namescontext_bias with curated termsCan still hallucinate or miss names; validate against reference audio
Multilingual interviewsLanguage detection or pinned languageEvaluate Arabic, German, English and accents separately
Sensitive recordingsServer-side access and retention controlsSpeaker labels do not verify consent or identity

Consider the difference between speaker attribution (“which voice spoke?”), speech recognition (“which words were spoken?”) and word alignment (“when did each word occur?”). A transcript can be perfectly spelled yet assign critical statements to the wrong speaker. This is why SXF recommends evaluating them with different scoring methods.

2026 VERSION MIGRATION

Voxtral Mini Transcribe 2 vs Voxtral 3: pricing, API IDs and breaking changes.

On October 20, 2026, Mistral announced Voxtral 3. Its migration guide maps the old pinned ID voxtral-mini-2602 to voxtral-mini-transcribe-3-0 (with alias voxtral-mini-transcribe-3). This does not make V2 and V3 drop-in equivalents.

It is not a controlled quality comparison; the newer model might reduce correction labor or change output behavior. The economic question is whether those changes lower cost per accepted hour.

  1. Replace your pinned V2 model string with the V3 model ID in a staging environment.
  2. Change timestamp_granularities=word to segment; V3 returns an error for word-level timestamp requests.
  3. Recheck your diarization parser and handle segments that overlap in time.
  4. Revisit context_bias and audio length, and retest previously misspelled names.
  5. Re-run a fixed corpus and compare WER, term accuracy, speaker attribution, timing quality and cost.
  6. Verify access, pricing tier, privacy handling and your V2 retirement schedule against current Mistral docs.

Separate the products: the historic Voxtral Mini Transcribe Realtime route covers streaming rather than file transcription, and it has its own V3 successor. Likewise, neither release should be mistaken for Gemini 3.5 Transcribe or GPT-Transcribe.

How to evaluate Voxtral 2 transcription quality: a 12-clip evidence protocol.

This SXF protocol is an original proposed experiment, not a claim that SXF has run paid model calls or determined the most accurate provider. Run the same human-approved reference audio on a version-pinned V2 endpoint (if still accessible), V3 and any competitor. Build a small local benchmark with 12 short consented clips: four languages (English, Arabic, German, Spanish) crossed with three conditions (clean speech, background noise, two overlapping speakers). Retain source consent and anonymize private details.

Keep at least two human reviewers blind to model identity for disputed words, and log unresolved disagreements. Report results by language and acoustic condition rather than hiding failures in a single average. For V3, record the loss of word timestamps as a feature difference, not a direct word-timestamp accuracy failure.

DEPLOYMENT DECISIONS

Best Voxtral 2 use cases — and when not to choose it.

MEETINGS

Speaker-aware notes

Use diarization to segment meeting turns, then manually verify names and action items. Do not treat speaker labels as identity verification.

MEDIA ARCHIVES

Subtitle preparation

Word timestamps can seed caption timing, but subtitle readability, line breaks and synchronization still require quality control. V3 timing changes are material here.

CONTACT CENTERS

Recorded calls

Track who spoke and review sensitive terms. Consent, access controls, retention rules and confidentiality matter before upload.

RESEARCH

Interview indexing

Transcripts can accelerate qualitative coding and search. Keep audio excerpts for verification and separate quotes from analysis.

NOT SUITABLE

Live streaming voice agents

Version 2's file model isn't a real-time streaming recognizer. Choose a realtime endpoint and test turn latency separately.

NOT SUITABLE

Unsupported chat or free weights

Its published contract is hosted transcription, not chat generation. The Premier model should not be described as freely self-hostable.

Operationally, encrypt audio at rest and in transit, define a retention period, avoid logging raw credentials or unredacted transcript content, and add human approval for medical, legal or financial records. Provider capability does not replace consent, accuracy validation or jurisdiction-specific compliance checks. DIRECT-ANSWER SEARCH QUESTIONS

Voxtral Mini Transcribe 2 FAQ: price, languages, API and migration.

What is the API model ID for Voxtral Mini Transcribe 2?

Use the pinned ID voxtral-mini-2602 with Mistral's /v1/audio/transcriptions endpoint, subject to the deprecated model's continuing availability. Do not rely on a mutable latest alias to remain on V2.

How much does Voxtral Mini Transcribe 2 cost?

Mistral's version-2 model card lists $0.003 per audio minute Standard ($0.18 per hour); its pricing table also lists $0.0003 per minute in the Batch tier. Check whether the deprecated endpoint is still offered in your workspace.

Does Voxtral Mini Transcribe V2 support Arabic?

Yes. Arabic is one of the 13 languages documented for V2. Actual transcription accuracy varies with dialect, speakers, noise and recording conditions.

Can Voxtral Mini Transcribe 2 separate speakers?

Yes. It supports speaker diarization for prerecorded audio. Speaker labels are not evidence of verified personal identity, and overlaps need manual checking.

Can Voxtral 2 return word-level timestamps?

Yes, in its archived V2 transcription interface. Word-level timestamps are removed in Voxtral 3, where you must request segment-level timing instead.

Is Voxtral Mini Transcribe 2 open source or self-hostable?

No open weights are listed for the Premier Mini Transcribe 2 model. The distinct Voxtral Realtime 2 checkpoint is the Apache-2.0 release; do not conflate the two.

Is Voxtral 2 still the newest Mistral transcription model?

No. Mistral released the Voxtral 3 family on October 20, 2026 and lists Mini Transcribe 2 in its deprecated model directory. Check the official migration document for replacement IDs and availability.

What changed in the Voxtral 2 to Voxtral 3 API migration?

The model ID changes from voxtral-mini-2602 to voxtral-mini-transcribe-3-0; word-level timestamps are no longer available, some context-bias rules change, and applications must handle overlapping segments appropriately.
