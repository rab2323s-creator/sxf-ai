GPT-6 Sol: a developer-grade reference, not just a model card.

The original GPT-6 Sol (gpt-6-sol) is OpenAI's September 2026 reasoning model for complex coding and tool-using agents. It supports a 1,050,000-token context window, 128,000 maximum output tokens, text and image input, and configurable reasoning from none to max.

This page gives direct answers on API pricing, long-context fees, prompt caching, the Responses API, benchmark evidence and GPT-6 Sol vs GPT-6.1 Sol—plus a reproducible SXF cost experiment using the exact published rate schedules. It does not mislabel supplier benchmark claims as independently tested results.

DIRECT SEARCH ANSWER · USD PER MILLION TEXT TOKENS

GPT-6 Sol API pricing: input, cached tokens, cache writes and output.

For a Standard API request with 272,000 or fewer input tokens, original GPT-6 Sol costs $2 input, $0.20 cached reads, $2.50 cache writes and $10 generated output per million tokens. Above 272,000 input tokens, input and cache rates double and the output rate increases by 50% for the whole request. The number of input tokens includes uncached input, cached reads and cache writes in the SXF cost scenarios.

Billable categoryInput ≤272KInput >272K
New input$2$4
Cached input read$0.2$0.4
Cache-write input$2.5$5
Generated output$10$15

Do not confuse the rates: a cache read is cheaper than a new input, while a cache write is more expensive. A new request does not automatically achieve a cache hit. Batch/Flex, Fast, tools and regional charges have separate policies and are deliberately excluded from this table. Check the current OpenAI API pricing reference and prompt-caching guidance before production budgeting.

Transparent methodology and limitations

Input tokens = new input + cache reads + cache writes. For each category, multiply the number of tokens by the matching published USD-per-million rate and divide by 1,000,000. If input tokens are strictly greater than 272,000, multiply all input/cache rates by 2 and the output rate by 1.5. The same formula is applied to both model IDs, with each model's own rates.

The CSV records all counts, calculated costs and the pricing tier used. The site-build test independently recalculates the study from the repository's versioned provider catalog and rejects pricing drift. Outcomes here show potential list-rate cost differences only. Real economics include response length, cache hits/misses, retries, tool calls, quality validation, regional processing, latency and processing mode. There is no measured success-rate or latency advantage claimed.

GPT-6 Sol vs GPT-6.1 Sol: which model is newer, cheaper and compatible?

GPT-6 Sol is the original September 22, 2026 model (gpt-6-sol). GPT-6.1 Sol arrived September 29, 2026 (gpt-6.1-sol) as the newer Sol offering. They are distinct API endpoints, with different knowledge cutoffs, cached-input prices and supported reasoning/tool configurations. A keyword like “gpt sol” is ambiguous: this page deliberately identifies both IDs rather than treating them as interchangeable.

COPYABLE DEVELOPER START · NO PRIVATE KEYS ON THE PAGE

How to call GPT-6 Sol using the OpenAI Responses API.

Use the exact original model ID gpt-6-sol and choose an available reasoning effort. Example below uses a short text prompt; adapt it for testing with real unit tests and human review. The SDK reads OPENAI_API_KEY from the environment. This snippet is illustrative and was not executed against a paid API as part of the SXF pricing study.

from openai import OpenAI

client = OpenAI()  # reads OPENAI_API_KEY
result = client.responses.create(
    model="gpt-6-sol",
    reasoning={"effort": "medium"},
    input="Review this code change. List risks and specific regression tests."
)
print(result.output_text)

How should production teams evaluate it?

  1. Build a representative held-out set of tasks with explicit acceptance criteria and hard failure cases.
  2. Record prompt, model ID, reasoning effort, tool configuration, version and output for each run.
  3. Measure task success, human corrections, end-to-end latency, actual input/cache/output usage and retry frequency.
  4. Run the same workload on GPT-6.1 Sol and Astra. Compare cost per validated result; keep provider launch benchmarks separate from your measurements.

For tool calling, prefer the Responses API per OpenAI's original Sol model card. For prompts with reusable prefixes, follow the current prompt-caching guidelines. Do not expose API keys in client-side code or GitHub commits.

DIRECT-ANSWER SEARCH INTENTS

GPT-6 Sol FAQ: pricing, usage, ChatGPT, coding and migration.

What is GPT-6 Sol?

GPT-6 Sol is the original OpenAI GPT-6 reasoning model released September 22, 2026 for complex coding and agentic tasks; its API model ID is gpt-6-sol.

What is the GPT-6 Sol model ID?

The original model identifier is gpt-6-sol; GPT-6.1 Sol uses the distinct gpt-6.1-sol API identifier.

How much does GPT-6 Sol cost?

At Standard short-context API prices per one million tokens, GPT-6 Sol costs $2 uncached input, $0.20 cached reads, $2.50 cache writes and $10 output. Long-context requests above 272,000 input tokens use higher rates across the whole request.

What is the GPT-6 Sol context window?

GPT-6 Sol supports a 1,050,000-token context window and up to 128,000 output tokens. Actual response quality and output length depend on task and settings.

Is GPT-6.1 Sol the same as GPT-6 Sol?

No. GPT-6.1 Sol is a newer September 29, 2026 release with a different model ID, lower cached-input rates and different reasoning/tool compatibility. The two models should not be treated as aliases.

Which GPT-6 Sol version is newer?

GPT-6.1 Sol is newer than original GPT-6 Sol; compare the exact provider model IDs when migrating.

Is GPT-6.1 Sol cheaper than original GPT-6 Sol?

The two models have identical Standard short-context uncached input, cache-write and output list rates, but GPT-6.1 Sol cached reads are $0.10 per million tokens versus $0.20 for original Sol. Actual savings depend on cache hit rate.

When does GPT-6 Sol long-context pricing apply?

The higher long-context tier applies when total prompt input exceeds 272,000 tokens. Input and cache rates double and output increases by 50 percent for the entire request.

Does GPT-6 Sol support none reasoning effort?

Yes. Original GPT-6 Sol supports none, low, medium, high, xhigh and max. GPT-6.1 Sol does not support none.

Does GPT-6 Sol support function calling?

Yes. The Responses API supports function calling and built-in tools. OpenAI documents Chat Completions tool calling for original Sol only when reasoning_effort is set to none.

Can GPT-6 Sol process images?

GPT-6 Sol accepts text and image inputs and produces text output, according to its OpenAI API model card.

What is GPT-6 Sol's knowledge cutoff?

OpenAI lists April 20, 2026 as the original GPT-6 Sol knowledge cutoff.

What did SXF test for GPT-6 Sol?

SXF published an original deterministic cost model across nine hypothetical token workloads, comparing original GPT-6 Sol and GPT-6.1 Sol rates. SXF did not conduct paid model-inference or quality benchmarks.

Are the benchmark numbers on this page independent?

No. The AutomationBench, Agents' Last Exam and DeepSWE scores on this page are explicitly attributed to OpenAI's September 2026 launch report and are not presented as SXF's own independent results.

How do I use the GPT-6 Sol API?

Use the OpenAI Responses API with model gpt-6-sol and a supported reasoning effort. Store the API key on the server or in an environment variable, not in browser source.

Is GPT-6 Sol available in ChatGPT?

API availability and ChatGPT subscription availability are separate products. Consult current plan documentation rather than assuming an API model ID appears in all ChatGPT model selectors.
