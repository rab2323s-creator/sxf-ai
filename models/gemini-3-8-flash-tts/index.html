Gemini 3.8 Flash TTS at a glance.

Gemini 3.8 Flash TTS is Google's flagship text-to-speech (TTS) model for natural narration, expressive acting, regional accents and sustained multi-turn dialogue. Supply a written transcript and voice settings through the Gemini API; the model generates speech audio. It is designed for audio production, not chatbot reasoning or live speech-to-speech calls.

Use gemini-3.8-flash-tts for audiobooks, podcasts, studio-style scripts and complex character delivery. Google lists 8,192 input tokens, 16,384 output-serving tokens and automatic language detection across 130+ languages. For lower-cost routine TTS, compare Gemini 3.8 Flash-Lite TTS.

VERIFIED MODEL SPECIFICATIONS

Gemini 3.8 Flash TTS: limits and features.

TEXT INPUT

8,192 input tokens

A script is supplied as text. This is an input-serving limit, not an eight-thousand-word promise: tokens vary with language and formatting.

GENERATED AUDIO

16,384 output tokens

The documented output-serving cap applies to the audio generation request. Output is audio, not regular chatbot text. Duration and token consumption are different concepts.

LANGUAGE COVERAGE

More than 130 languages

Google lists English, Standard Arabic, Egyptian Arabic, Hindi, Spanish and many more, with automatic language detection. Quality should still be evaluated for each locale and voice.

SPEAKER CONTROL

Single or two-speaker turns

Prebuilt voices work for a single-speaker request or two different speakers in one scripted exchange. Custom or replicated voices in multi-character work require separate calls per speaker.

VOICE LIBRARY

Prebuilt and designed voices

Select Google voices such as Kore or Puck; use the Extended Voice Library, Voice design or Voice replication where supported. Permission is important for voice replication.

API MODES

Standard, Batch, Flex, Priority

Google lists multiple paid serving tiers. Batch and Flex have lower rates than Standard; Priority costs more. Available capacity and latency differ by serving tier.

Not supported as a general-purpose model: Google lists function calling, code execution, search grounding, structured text output, thinking and Live API operation as unavailable on this specific TTS model. Do not confuse it with the multimodal reasoning model Gemini 3.8 Flash.

VOICE GENERATION & PROMPTING

How to control pronunciation, emotion and multi-speaker speech.

TRANSCRIPT

Write what should be said

The text field is treated as verbatim speech. Do not prefix your script with plain-text stage directions that could be read aloud.

TURN-LEVEL STYLE

Use speech_metadata.style

Place delivery instructions such as “warm and enthusiastic” or “whispered urgently” in structured metadata rather than inside the spoken transcript.

SHORT VOCAL EVENTS

Use inline tags sparingly

Tags such as <short pause>, <sigh> and <laugh> belong at the exact point where the action should occur.

VOICE IDENTITY

Pick a stable voice

Use prebuilt or designed voices for character continuity. Complex permanent accent or identity characteristics belong in voice selection or design, not transient style instructions.

Two-speaker scripts: define both speakers under generation_config.speech_config.speakers, then annotate each spoken turn with a matching speech_metadata.speaker. Google limits single-request multi-speaker synthesis to two speakers using prebuilt voices. For more characters or custom/replicated personas, render speaker turns individually and combine audio carefully.

Voice replication: the ability to synthesize a voice does not grant rights to copy someone else's identity. Obtain appropriate consent and use safeguards against deceptive impersonation. Refer to Google's speech-generation guide for voice design, replication and supported audio formats.

GOOGLE GEMINI API EXAMPLE

Generate WAV speech with Gemini 3.8 Flash TTS in Python.

This uses Google's documented Interactions API request shape, not an older preview-model prompting format. Install an up-to-date google-genai SDK (Google documents Python 2.25.0 or later).

import base64
from google import genai

client = genai.Client()  # GEMINI_API_KEY in environment
interaction = client.interactions.create(
    model="gemini-3.8-flash-tts",
    input=[{
        "type": "user_input",
        "content": [{
            "type": "text",
            "text": "Welcome to our audio guide!",
            "annotations": [{
                "type": "speech_metadata",
                "style": "warm and friendly",
            }],
        }],
    }],
    response_format={"type": "audio"},
    generation_config={
        "speech_config": [{"voice": "Kore"}]
    },
)
with open("narration.wav", "wb") as file:
    file.write(base64.b64decode(interaction.output_audio.data))
01

Authenticate: set GEMINI_API_KEY in your environment and install Google's maintained SDK. Do not put a secret API key into a website's client-side JavaScript.

02

Send structured turns: the model ID is gemini-3.8-flash-tts; provide text with optional speech_metadata and an explicit voice.

03

Save WAV directly: Gemini 3.8 unary requests return audio/wav by default, including a RIFF header. Do not wrap this response in a second WAV header.

04

Use the right format for streaming: for chunk concatenation, request raw PCM (audio/l16) or remove WAV headers, and confirm that audio frames use the expected 24 kHz format.

For a production system, test pronunciation and speaker consistency on representative scripts before shipping. The model is useful for controlled speech generation, but should not be presented as the bidirectional voice interface provided by Google's Gemini 3.8 Live model.

LIMITATIONS & PRODUCTION CHECKLIST

What to verify before deploying this TTS model.

01

Exact recitation: use a clean transcript and structured metadata. Always listen to samples for pronunciation, numeral reading, breath sounds and tag interpretation, especially in niche dialects.

02

Long-form delivery: the model targets stable extended narration, but the per-request token limits still apply. Segment large books into coherent passages and perform listening QA across boundaries.

03

Custom voices: two-speaker synthesis in a single request uses prebuilt voices. Use separate calls for custom or replicated voices across multiple characters.

04

Billing: text input and generated audio are metered differently, with the rate schedule changing in 2027. Google also lists different Batch, Flex and Priority tiers.

05

Rendering: avoid re-wrapping default WAV output and preserve sample format if concatenating audio chunks. A speech-synthesis pipeline is not an automatic transcription or real-time conversation stack.

QUESTIONS ANSWERED

Gemini 3.8 Flash TTS FAQ.

What is Gemini 3.8 Flash TTS?

Google's text-to-speech model for expressive, studio-style narration, regional accents and multi-speaker dialogue. It takes text and returns audio; it is not the Gemini Live API.

What is the Gemini 3.8 Flash TTS model ID?

Use gemini-3.8-flash-tts in the Gemini API. It is different from the general-purpose gemini-3.8-flash model.

How much does Gemini 3.8 Flash TTS cost?

Through December 31, 2026, Google lists $0.50 per million text input tokens and $9 per million generated audio output tokens on Standard paid API; from January 1, 2027 the published rates are $1 and $18.

How much is a minute of generated speech?

At Google's 25 output audio tokens per second, 60 seconds is 1,500 audio tokens. That costs approximately $0.0135 at the introductory Standard rate, before text input charges.

Does Gemini 3.8 Flash TTS support multiple speakers?

Yes. In a single request Google supports up to two configured speakers using prebuilt voices. Each dialogue turn needs a matching speech_metadata.speaker value.

Can I control speaking style and add pauses?

Yes. Use speech_metadata.style for turn-level performance and inline tags such as <short pause> or <laugh> for point-in-time vocal events.

Does Gemini 3.8 Flash TTS support Arabic?

Yes. Google's supported-language list includes Standard Arabic and Egyptian Arabic; the model automatically detects input language. Actual pronunciation should be evaluated with your own transcripts.

What is the context window and output limit?

Google documents an 8,192-token input limit and a 16,384-token output serving limit. Audio duration is billed by generated audio tokens, not ordinary text output.

Is Gemini 3.8 Flash TTS the same as Gemini Live?

No. Flash TTS converts a supplied transcript to audio, whereas the Live API is intended for interactive streaming, multimodal conversation.

Flash TTS vs Flash-Lite TTS: which should I choose?

Choose Flash TTS for maximum vocal nuance, difficult pronunciations, dialect coverage and long narration. Choose Flash-Lite TTS for lower-cost, high-throughput or everyday voice production; both share the same request schema.
