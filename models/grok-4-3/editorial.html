What is Grok 4.3?

Grok 4.3 is a paid xAI reasoning-oriented model that takes text and image inputs and generates text. Its official API model identifier is grok-4.3, and its published context capacity is one million tokens. Typical applications include large document analysis, long-context reasoning, image understanding, developer tools and structured business workflows.

A one-million-token context window does not mean that you can request one million output tokens. No standalone maximum response size or knowledge cutoff should be invented when the official source is silent.

Should you use a million-token prompt or RAG?

A 1M context capacity permits substantial document corpora, repository files and longer conversations. But unnecessarily large prompts can cost more, especially above the 200K pricing boundary. Retrieval augmented generation, targeted search, compression and verified citations often offer a better fit for focused queries.

Test how source-grounded answers change with full-context ingestion versus selected passages. Measure costs per correct answer, retrieved-evidence support, timeouts and context waste—not context size alone.

Reasoning effort, response quality and prompt caching

Grok 4.3 publishes configurable reasoning capabilities. The list of effort names can differ between overview docs, per-model documentation and API service channels. Validate the value you intend to use before shipping and track real token use and response time.

A cached-token discount applies only when a request actually qualifies for caching and its usage is recorded. Do not assume all repeated instructions are automatically billed as cached. Use xAI's usage and cost-tick reporting as the source for invoice reconciliation.

Can Grok 4.3 see or generate images?

It supports image input understanding and text output, not image generation as a normal output modality. Test charts, documents, screenshots and forms on permission-cleared images. Score extracted labels and numbers against verified references and do not infer perfect OCR or visual reasoning from mere modality support.

Grok 4.3 FAQ

What is Grok 4.3?

A text-output xAI reasoning model with text/image input and one-million-token context.

What is the Grok 4.3 API model name?

grok-4.3.

How much does Grok 4.3 cost?

Below 200K prompt tokens, $1.25 input and $2.50 output per million; at 200K or above, $2.50 input and $5.00 output.

What is Grok 4.3's context window?

1,000,000 tokens; this is not a published maximum output guarantee.

Does Grok 4.3 support caching?

Published cached input prices are $0.20 short and $0.40 long per million when caching applies.

Can I use Grok 4.3 with function calling?

Yes in compatible API workflows; validate arguments, authority and side effects.

Does Grok 4.3 generate images?

It accepts images and produces text; image generation is not the model's normal output.

Did SXF benchmark Grok 4.3 on real prompts?

No. SXF constructed a reproducible 48-case synthetic pricing experiment; no paid API inference or quality testing.
