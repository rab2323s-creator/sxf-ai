DIRECT ANSWER

What is Cohere North Small Translate 1.0?

North Small Translate is a decoder-only, sparse mixture-of-experts model optimized for translation, not a general chatbot or a document-formatting service. Cohere describes 128 experts, eight selected per token plus shared experts. Only a subset of the 218B weights is active per token, but self-hosting must account for the total checkpoint and inference overhead.

The official API identifier in the current Cohere V2 guide is north-small-translate-1.0; the permanent SXF page URL retains north-small-translate-1-0. The older Cohere V1 model listing uses a 1-0 identifier, so copy the documented ID for your chosen API version rather than deriving it from this page's slug.

Quick verdict

Consider this model when you need controlled multilingual text translation, API integration or eligible on-premises research. Use a translation platform instead when the main need is file layout reconstruction, human review workflows, translation memory or collaboration. Compare your real language pairs before rollout.

DEVELOPER GUIDE

How to use North Small Translate with the Cohere API.

Cohere's official example uses ClientV2 and a standard translation instruction. Install the Cohere SDK, store your API key in an environment variable, and submit the text with the target language explicitly requested. The code below follows that documented Chat V2 approach; run it locally with your own key.

Python · Cohere Chat V2
import os
import cohere

co = cohere.ClientV2(api_key=os.environ["COHERE_API_KEY"])
source_text = "Enterprises need accurate translations."
target_language = "French"

response = co.chat(
    model="north-small-translate-1.0",
    messages=[{
        "role": "user",
        "content": (
            f"Translate everything that follows into {target_language}:\n\n"
            f"{source_text}"
        )
    }],
)
print(response.message.content[0].text)

Install with pip install cohere. Never publish an API key in source code, Git, telemetry or client-side JavaScript. Confirm current limits on Cohere rate limits.

Translation production checklist

01 · Protect source text

Redact unnecessary personal data and apply your organization's transfer policy before using a hosted API.

02 · Specify the target

Choose a locale when necessary: Modern Standard versus regional Arabic, for example; retain placeholders and special tokens.

03 · Validate output

Review glossary consistency, currency, numbers, negation, safety instructions and formal register with bilingual reviewers.

04 · Preserve layout

Segment and reassemble HTML, subtitles, PDFs or spreadsheets in your application; the model itself returns text.

DIRECT SEARCH QUESTIONS

North Small Translate 1.0 frequently asked questions.

What is North Small Translate 1.0?

A Cohere and Cohere Labs sparse mixture-of-experts machine translation model with 218 billion total parameters, 25 billion active parameters, and a 16,000-token context window.

What is the Cohere API model ID?

Use north-small-translate-1.0 with Cohere Chat V2, as documented in Cohere's current model guide. Older reference materials use a hyphenated 1-0 suffix; confirm your endpoint before deploying.

Is North Small Translate free?

Cohere says the Chat V2 API is free for trial and production keys until their applicable rate limits are reached. This is not an unlimited paid-production pricing commitment.

Can I use North Small Translate commercially?

The downloadable weights are licensed CC BY-NC 4.0 for non-commercial use. Ask Cohere about commercial deployment rights; API access remains subject to separate service terms.

How many languages does North Small Translate support?

Cohere publishes a list of 50 languages with additional Arabic and Chinese locale variants, including Arabic, English, German, French, Japanese, Korean, Ukrainian, Hindi and Spanish.

How much GPU memory does North Small Translate need?

Cohere suggests two NVIDIA H100s or one B200 for W4A16, four H100s or two B200s for FP8, and eight H100s or four B200s for BF16. Treat these as format-specific deployment guidance, not tested SXF minimums.

How does North Small Translate compare with DeepL and Google Translate?

Cohere reports a WMT26 all-language score of 83.60 for North Small Translate, versus 81.37 for DeepL NextGen and 68.20 for Google Translate in its own GPT-5.6-Sol-judged evaluation. These are provider-reported results, not independent SXF tests.

Does North Small Translate translate documents and PDFs directly?

Its documented API is text-in and text-out. Applications must extract document text, retain structure, translate passages, and rebuild formatting separately.
