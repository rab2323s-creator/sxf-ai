QUICK ANSWERS

What models are in the GPT-6 family?

OpenAI currently lists GPT-6 Astra, GPT-6 Sol and GPT-6 Luna as the flagship GPT-6 family.

What is the GPT-6 context window?

Astra, Sol and Luna each have a 1,050,000-token context window and support up to 128,000 output tokens.

How much does GPT-6 cost in the API?

For Standard API requests up to 272K input tokens, Astra is $10 input / $50 output per 1M tokens, Sol is $2 / $10, and Luna is $0.10 / $0.50. Cached-input rates are lower.

What is each GPT-6 model for?

OpenAI positions Astra for the hardest end-to-end work, Sol for complex coding and agentic workflows, and Luna for efficient high-volume tasks.
