EXACT-MATCH SEARCH ANSWERS

How much does GPT-6 Astra cost per million tokens?

OpenAI lists $10 uncached input, $1 cached-input read, $12.50 cache write and $50 output per million text tokens in Standard mode for prompts with up to 272,000 input tokens. For prompts with more than 272,000 input tokens, the entire request uses $20 input, $2 cached read, $25 cache write and $75 output per million tokens. The boundary is strictly greater than 272,000, not greater than or equal to it.

Cache-write retention: the prices above use a 30-minute minimum retention period. A 12-hour cache-write costs $25 per million short-context write tokens ($50 above 272K), not $12.50. The 12-hour value replaces the shorter-duration write rate; do not add both. Cached-read prices are unchanged. These are provider-published Standard rates, not a claim that every request creates a cache entry. See OpenAI prompt caching and API pricing.

SXF billing boundary lab: does one extra input token change the total price?

We designed six controlled, hypothetical token workloads and recomputed their list-price cost for Astra and GPT-6.1 Sol using the documented rates, including cache reads and cache writes. The dataset is downloadable as CSV with exact token counts and results. This is a reproducible pricing-model calculation, not an inference call or a claim about either model's output quality.

Method and reproducibility

For each request, input_total = new_input + cached_read + cache_write. If input_total > 272000, multiply all input and cache rates by 2 and the output rate by 1.5. Otherwise use short-context rates. Multiply each token count by its applicable per-million price and sum. The dataset contains modelled scenarios, not customer invoices. Cache-write counts assume those tokens are billed as writes; whether a request actually hits or writes cache depends on the serving system.

These scenarios use the default 30-minute cache-write tier. A separate 12-hour cache-write estimate is available in the interactive calculator; it changes the price of cache writes only, not cached reads. These scenarios deliberately fix output token counts. They do not predict reasoning-token consumption, completion quality, tool usage, failed retries or human-review costs. Read the source pricing policy alongside the CSV to reproduce the arithmetic.

DEVELOPER REFERENCE

How to use GPT-6 Astra with the OpenAI Responses API

Set the exact gpt-6-astra model ID, choose a documented reasoning effort and validate the response before acting on real systems. Tool calling and structured outputs are supported; a model's output still requires independent checking for consequential work.

from openai import OpenAI

client = OpenAI()  # uses OPENAI_API_KEY from environment
response = client.responses.create(
    model="gpt-6-astra",
    reasoning={"effort": "high"},
    input="Review this migration plan. Identify assumptions, risks, and tests."
)
print(response.output_text)

For prompt-heavy workflows, observe actual billed new input, cached reads, cache writes and output tokens before using the SXF estimator as a budget. Also evaluate task accuracy, retries and human validation. See model capabilities and GPT-6 development guidance.

DECISION FRAMEWORK

GPT-6 Astra vs GPT-6.1 Sol: when is Astra worth paying for?

At short-context Standard list rates, Astra's uncached input and output tokens are five times GPT-6.1 Sol's. The price multiple is not a performance multiple. Start with a labelled evaluation set of your own tasks, then compare cost per accepted result rather than cost per token alone.

CHOOSE ASTRA TO TEST

Failure is costly

Complex computer use, multi-step coding, expert research and high-stakes document work where measured error reduction may offset more expensive tokens.

CHOOSE SOL AS BASELINE

Throughput and value matter

Routine-to-complex development and agent tasks with clearly testable acceptance criteria. Use GPT-6.1 Sol to benchmark economics before upgrading.

BEFORE DEPLOYMENT

Run a task-level pilot

Use held-out cases, record success and failure reasons, version the prompts and measure latency, API usage, tool charges and human corrections.

SEARCH-INTENT FAQ

GPT-6 Astra frequently asked questions

What is GPT-6 Astra?

GPT-6 Astra is OpenAI's highest-capability GPT-6 tier for demanding reasoning, computer use, coding, research and professional work.

What is the GPT-6 Astra model ID?

The official OpenAI API model ID is gpt-6-astra.

How much does GPT-6 Astra cost per million tokens?

At Standard short-context rates, GPT-6 Astra costs $10 per million uncached input tokens, $1 per million cached input reads, $12.50 per million 30-minute cache writes, $25 for 12-hour cache writes, and $50 per million output tokens. Longer prompts have higher rates.

What is the difference between 30-minute and 12-hour cache writes?

For Standard short-context GPT-6 Astra, cache writes are $12.50 per million tokens for a 30-minute minimum cache lifetime and $25 for 12 hours. These are full write prices, not additional surcharges; cached reads cost the same for either duration.

What is the context window of GPT-6 Astra?

The documented context window is 1,050,000 tokens, with a separate maximum output limit of 128,000 tokens.

When does long-context pricing start for GPT-6 Astra?

For prompts exceeding 272,000 input tokens, all input and cache rates double and output rates rise by 1.5 times for the full request. Exactly 272,000 input tokens stays at short-context rates.

Does GPT-6 Astra accept images?

Yes. OpenAI documents text and image input with text output.

Which reasoning effort values does GPT-6 Astra support?

Astra supports low, medium, high, xhigh and max reasoning effort, with medium the default; none is not a supported effort setting.

How do I call GPT-6 Astra with the API?

Use OpenAI's Responses API with model gpt-6-astra and a supported reasoning effort. Evaluate output quality and token usage before production use.

Is GPT-6 Astra better than GPT-6.1 Sol?

Astra is positioned for the hardest tasks, while GPT-6.1 Sol has substantially lower Standard token list prices. Compare on representative tasks and cost per accepted result rather than assuming that a higher token price guarantees better results.

Did SXF run GPT-6 Astra inference benchmarks?

No. SXF's original experiment is a deterministic pricing calculation using six published token-count scenarios and the official price schedule. Model performance numbers shown separately are attributed to OpenAI's launch report.

Is the SXF calculator a real API bill?

No. It estimates Standard text-token list charges for hypothetical workloads. Actual usage, caching, other processing modes, tools and deployment fees can change final bills.
