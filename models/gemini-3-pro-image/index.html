Stable provider-native model ID is gemini-3-pro-image; Nano Banana Pro is its consumer-facing name.

Standard paid API rates: $2.00 per 1M text/image input tokens and $120.00 per 1M generated IMAGE output tokens. Text and thinking output is priced separately at $12.00 per 1M text tokens.
