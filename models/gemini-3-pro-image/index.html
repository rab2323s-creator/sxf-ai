What is Nano Banana Pro (Gemini 3 Pro Image)?

Nano Banana Pro is the public name for Gemini 3 Pro Image, Google's premium, reasoning-enabled image-generation and image-editing model. Its official developer identifier is gemini-3-pro-image. The model creates images from text, revises supplied images conversationally and can return mixed text-and-image content, making it useful for professional visual assets rather than only single-prompt artwork.

Key facts: images at 1K, 2K and 4K; a published 65,536-token input limit and 32,768-token output limit; text and image input; text and image output; supported Google Search grounding, thinking and Batch API. The Google developer API is paid for this model. An ordinary text-generation cost estimate is not a reliable image-generation quote.

Nano Banana Pro pricing: cost per image and Batch alternatives.

For Gemini 3 Pro Image, Google lists paid Standard image output at $120 per million generated image tokens, equivalent to approximately $0.134 for a 1K or 2K image and $0.24 for a 4K image. Input text and image tokens are billed at $2 per million. Text and thinking output cost $12 per million tokens, separately from image output. Pricing depends on everything processed by a request, not just the final image size.

IMAGE GENERATION AND EDITING

What can Nano Banana Pro do with images and references?

TEXT TO IMAGE

Create professional visual assets

Build product hero images, stylized campaign layouts, illustrations and concept compositions from a description of the subject, scene, lighting, typography and camera angle.

Example prompt: “Create a 4:5 premium skincare campaign photo of an amber bottle on pale travertine with warm daylight. Exact headline: ‘Everyday Ritual’. Keep the label readable and the shadows natural.”

CONVERSATIONAL IMAGE EDITING

Modify an existing composition

Provide an image with an instruction, such as changing the lighting, rearranging products or localizing visible copy while preserving brand identity. Iterate with follow-up instructions and inspect the results between revisions.

Example edit: “Keep the bottle shape, logo placement and product color unchanged. Replace the environment with a bright bathroom counter and create soft morning reflections.”

MULTI-REFERENCE ART DIRECTION

Combine people, products and styles

Use reference images to define recognizable people, objects and style cues. Google documents a total reference-image limit with separate high-fidelity guidance for objects and characters.

Example prompt: “Use the chair in image 1, room layout in image 2 and fabric swatch in image 3. Preserve the chair silhouette while matching the new material and perspective.”

TEXT-HEAVY GRAPHICS

Infographics and localization

Specify exact quoted text, hierarchy, intended reading order, font character and language. Reasoning can help with complex layouts, but spelling, translated copy, numerical charts and regulated claims need editorial verification.

Google's image-generation and editing guide explains multi-turn edits, references, thinking and professional asset production. High-fidelity reference limits are guidance about particular subjects, not a promise of perfect consistency.

OUTPUT DIMENSIONS

Nano Banana Pro 4K resolution and aspect-ratio examples.

The image size tier (1K, 2K or 4K) and aspect ratio are separate controls. A 4K landscape image need not be a 4096×4096 square. Google's published Gemini 3 Pro Image size table gives the following examples:

DEVELOPER INTEGRATION

How to call the Nano Banana Pro API with Gemini.

Use the stable model ID gemini-3-pro-image with a Gemini API key. The following REST example uses the Google Interactions API and requests an image with a 4:5 aspect ratio at the 2K tier. Keep your API key on the server; the response includes generated image data that your application should save appropriately.

curl -s -X POST \
  "https://generativelanguage.googleapis.com/v1beta/interactions" \
  -H "x-goog-api-key: $GEMINI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3-pro-image",
    "input": "Create an editorial product shot of a ceramic perfume bottle, soft window light, crisp readable label.",
    "response_format": {
      "type": "image",
      "mime_type": "image/png",
      "aspect_ratio": "4:5",
      "image_size": "2K"
    }
  }'
01

Generate: specify gemini-3-pro-image, a descriptive prompt and response_format with an image type, desired aspect ratio and image size.

02

Edit: provide text and image inputs together, and describe the precise change and any elements to keep unchanged.

03

Process mixed outputs: for an interaction that returns illustrations alongside text, inspect the response steps and all content blocks instead of assuming a single output_image value.

04

Review costs and safety: budget separately for image output, text/thinking output, image inputs and optional Search grounding. Verify brand rights, factual diagrams and textual accuracy.

Technical examples and the current request schema are documented in Google's official image-generation guide. This example intentionally does not mix the older generateContent response structure with Interactions API fields.

IMAGE + TEXT

WORKING PROMPTS

How to get more reliable Nano Banana Pro image results.

01

Define a complete visual brief: describe subject, composition, intended use, materials, lighting and camera angle rather than supplying only a style adjective.

02

Quote exact words: write product names, poster titles and localization text verbatim. Check legibility, spelling, brand marks and small print after generation.

03

Describe edits separately from invariants: specify what should change and what must remain identical across versions, such as a product's silhouette or a character's clothing.

04

Assign reference images to roles: make it clear which image governs the product, person, environment or style. Don't assume every reference has equal fidelity.

05

Match size to delivery: generate quick drafts at 1K/2K and reserve 4K for final layouts. Output size, thinking and Search can affect final request costs.

06

Verify factual visuals: fact-check any chart axes, numerical claims, medical illustrations, maps and current-events content even when grounding is enabled.

These are editorial production recommendations informed by Google's documented model capabilities. No prompt guarantees exact brand fidelity, flawless text rendering or factual accuracy.

WHEN TO CHOOSE PRO

Best Nano Banana Pro use cases and important limitations.

ECOMMERCE

High-fidelity product mockups

Place a familiar package in different sets while working from reference images. Inspect logo position, geometry and material details.

BRAND + LOCALIZATION

Posters and translated visuals

Create layouts with multiple lines of text and adapt designs between languages, then review copy and typography carefully.

EDUCATION + EDITORIAL

Infographics and illustrated guides

Use text-and-image output to draft diagrams, stories and visual explanations. Verify factual assertions and citations independently.

CREATIVE DIRECTION

Multi-reference composition

Control products, people and styling across iterations with references and a clear edit history.

Boundaries: the model does not offer a free Gemini API tier, function calling, structured output mode, caching or Live API. Exact factual text and reference consistency are not guaranteed. It is a hosted image-generation service, not a locally self-hostable open-weights model.

NANO BANANA PRO FAQ

Frequently asked questions about Gemini 3 Pro Image.

01

What is Nano Banana Pro? Nano Banana Pro is Google's premium Gemini 3 Pro Image model, designed for complex image generation and conversational editing, accurate visual text, localization and reference-guided asset production.

02

What is the Nano Banana Pro API model ID? Use gemini-3-pro-image in the Gemini API. Nano Banana Pro is the product name; the endpoint is distinct from gemini-3.1-flash-image and gemini-nano-banana-2.1.

03

How much does Nano Banana Pro cost per image? Google's Standard API guide estimates $0.134 per 1K or 2K image, and $0.24 per 4K image. Prompt input, text or thinking output and Search grounding can increase the final request cost.

04

Is Nano Banana Pro free through the Gemini API? Google's Gemini 3 Pro Image pricing table does not list a free API tier. Google AI Studio availability and consumer subscription limits are separate from the paid developer API.

05

What resolutions and aspect ratios are supported? The Google image-generation guide documents 1K, 2K and 4K output, with aspect ratios including 1:1, 2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9 and 21:9.

06

How many reference images can Nano Banana Pro use? Google documents a maximum of 14 input reference images for Nano Banana models. Its Gemini 3 Pro Image guidance separately specifies up to six objects with high fidelity, up to five characters for consistency and up to three style references.

07

Does Nano Banana Pro support image editing and accurate text? Yes. It handles conversational image editing, branded layouts, legible text and visual consistency. Exact logos, product labels, factual claims and small type still require human quality review.

08

Can Nano Banana Pro use Google Search grounding? Yes. Gemini 3 Pro Image supports grounding with Google Search for time-sensitive factual context. Search usage can incur separate charges and generated charts or claims still require source verification.

09

Does Nano Banana Pro have a Batch API? Yes. Google publishes Batch pricing of approximately $0.067 per 1K/2K image and $0.12 per 4K image, excluding other request costs. Batch is suited to asynchronous production rather than instant editing.

10

Does Nano Banana Pro support interleaved text and images? Yes. Gemini 3 Pro Image can produce mixed text and image blocks in a single interaction. When building applications, process all response steps rather than assuming a single image response.

11

Nano Banana Pro vs Nano Banana 2.1: which should I choose? Use Nano Banana Pro for demanding professional creative control and high-fidelity visual work; consider Nano Banana 2.1 for lower-cost high-volume image production. Compare model capabilities and actual results with your own prompts.

12

Does Nano Banana Pro add an AI watermark? Google states that all generated Nano Banana images contain an invisible SynthID watermark. Review the current documentation before making claims about export metadata or downstream detection.
