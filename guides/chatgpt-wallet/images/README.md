## Image discovery and distribution

- Both image URLs are present as regular, visible `<img>` tags with descriptive English alt text, intrinsic dimensions and full-resolution links.
- `TechArticle.image` references two `ImageObject` entries and `WebPage.primaryImageOfPage` identifies the first.
- The first image is used in the article's Open Graph and Twitter image metadata.
- The article's `<url>` in `sitemap.xml` includes both `image:image` locations.
- The presentation uses the correct 40:21 aspect ratio and `object-fit:contain` to avoid clipping text.
- These steps make the assets available for search discovery but cannot guarantee Google Images indexing, ranking, or rich results.

If replacing either WebP, keep the filename and update declared dimensions in HTML, CSS and JSON-LD if its native dimensions change.
