FLUX 3 Image Klein:
8GB VRAM, ComfyUI Setup, License & Cost

Can you really run Black Forest Labs' new open-weight image model on an 8GB GPU? Yes, through a specific low-memory path—not every runtime and not every checkpoint. This guide separates source-backed facts from assumptions, then helps you choose your setup without inventing performance numbers.

Published 27 Oct 2026Primary release 15 Oct 2026Evidence Vendor + independent reports, clearly labeledScope Image generation and editing, not local LLMs
DIRECT ANSWER

FLUX 3 Image Klein can run locally on some 8GB NVIDIA RTX GPUs using the INT8 path in ComfyUI. Do not confuse that with the memory needed by the full reference pipeline.

Black Forest Labs' October 15 release states that FLUX 3 Image Klein has 5.6B image-generator parameters, an INT8 ComfyUI/Diffusers path on cards as small as 8GB VRAM, and both distilled and base checkpoints. The prompt upsampler, text encoder, model precision, runtime offloading and image size determine whether your actual pipeline fits. This is not a universal 8GB guarantee.

If you want a starting choice: use ComfyUI + the official gated INT8 files + the official workflow for a low-VRAM investigation; use the distilled checkpoint for ordinary generation; verify the actual commercial license before deploying at work. For guaranteed results, measure your exact workflow.

01 / WHAT IS VERIFIED

FLUX 3 Image Klein: specifications, supported tasks and the exact 8GB claim

Black Forest Labs published FLUX 3 Image Klein on October 15, 2026. It is an open-weights image generator and editor derived from the FLUX 3 family, not a chat LLM. It can make images from prompts, edit reference images, work with up to ten references, produce native 4K output and use bounding boxes to control layouts. The image transformer has 5.6 billion parameters; the separately loaded text encoder is not included in that count. Official release and technical details.

03 / PRACTICAL SETUP

How to run FLUX 3 Image Klein locally in ComfyUI, step by step

  1. Check the hardware and system memory. Confirm your GPU's dedicated VRAM, available system RAM, disk capacity and a recent compatible GPU driver. A low-memory GPU may use CPU offloading, so host RAM and storage throughput matter.
  2. Install or update ComfyUI. Use the current official ComfyUI version and supported Python/CUDA combination; follow upstream installation instructions rather than arbitrary community scripts.
  3. Accept the official model license. Sign into Hugging Face and accept the access terms for the official ComfyUI weights repository. A gated download failure is not a CUDA error.
  4. Choose the correct release files. For a low-VRAM RTX card, use the repository's documented INT8 transformer and compatible text encoder. The autoencoder is another necessary component. Do not mix checkpoint variants and outdated loader nodes.
  5. Import the official ComfyUI workflow. Use the vendor-provided workflow matching your variant and update any missing nodes. Place each downloaded file in the directories described by the official workflow documentation; locations can change with ComfyUI versions.
  6. Begin with the distilled checkpoint and a 1MP image. Start with one detailed prompt, no reference images, and the documented step settings. Record first-run warmup separately from steady-state generation time.
  7. Check peak memory, not download size. Monitor GPU and system RAM while generating, editing and adding references. If memory is exhausted, check whether the prompt upsampler or encoder is offloaded; do not assume reducing sampling steps will solve memory residency.
  8. Run an edit and a repeatability check. Test a realistic reference edit and at least three repeated runs; record output quality and failure rate before promising production capacity.
Official starting point: Black Forest Labs' ComfyUI model files. There are independent step-by-step GPU measurements, including ComputingForGeeks' October 2026 test. SXF has not independently run a GPU benchmark for this page; the following setup is source-verified guidance, not an invented personal test.

What about Diffusers and command-line inference?

The official model card documents other inference paths and the specific model organization. These may use separate model components and very different memory budgets. Follow the repository's current installation and invocation instructions; a working ComfyUI INT8 graph does not establish that a BF16 reference CLI will fit the same card.

04 / THE MEMORY TRAP

Why an “8GB model” may use much more memory in another setup

There are at least four distinct numbers that get mixed together in articles about local image models: transformer weight file size, full pipeline storage footprint, peak GPU VRAM at inference, and host RAM used by offloading. They are not interchangeable.

Official model fact

5.6B parameters

Applies to the image transformer. It does not count the separate text encoder or prompt upsampler.

Official compressed weights

5.6GB FP8 weights

This is a component weight figure quoted by BFL—not proof that the complete job fits inside 5.6GB VRAM.

Documented low-memory route

8GB INT8 ComfyUI

Supported as a route for some NVIDIA RTX configurations. GPU architecture, offloading and image parameters remain decisive.

External research pipeline

Higher memory possible

The reference model card shows much larger peak numbers for its complete run on specific data-center hardware.

Why prompt upsampling changes the result

Some FLUX 3 workflows expand a short user request into a detailed image caption with a separate model. Running that model on the GPU creates additional residency and processing costs. The model card distinguishes its reference pipeline from the ComfyUI INT8 pathway; read those sections before comparing VRAM figures from two tutorials.

The honest GPU test protocol

For each card report: GPU model and VRAM, driver, runtime version, weight build, text encoder, prompt upsampler on/off, offload, output resolution, reference-image count, first-run and warm latency, GPU and system-RAM peaks, and errors. A single “seconds per image” figure without those conditions cannot be generalized.

06 / IMAGE API ECONOMICS

FLUX 3 Klein API price: how much for 100, 1,000 or 10,000 images?

Black Forest Labs' October 15 announcement states that 1K image generation starts at $0.009 through the FLUX 3 Image Klein API. This is a starting rate, not a statement that every resolution, edit, reference-image composition or contract has the same price.

Calculation: requested images × (1 + assumed rerun rate) × $0.009. This is a lower-bound scenario at the announced 1K starting rate, not a vendor quote. It excludes hosting, storage, review time, variant-specific pricing and regional charges.

Why cost per useful image beats cost per generated image

Suppose a model has a lower raw API price but its outputs require multiple corrections, more human review, or extra reference-image preparation. The actual business cost is (generation + retries + editing + review + storage) / accepted deliverables. Use the same acceptance rubric and sample prompts across models. Our AI model cost tool explains the broader accounting logic for model services, but it should not be interpreted as a verified FLUX-specific price feed.

07 / THE LICENSE DECISION

Is FLUX 3 Image Klein free for commercial use?

The weights are released under the FLUX Kommunity License. The release announcement says eligible individuals and companies below an annual revenue threshold may receive free commercial rights under the license, while larger commercial self-hosted deployments have licensing options. This is a description of the vendor's announcement, not a substitute for the binding terms.

Check 1

Who is deploying?

Is the licensee an individual, organization, contractor or a larger consolidated business? Check the definition used in the actual license.

Check 2

What is being commercialized?

Generating images as an end user, serving a hosted API, redistributing weights, training, fine-tuning and embedding into a product can carry different conditions.

Check 3

Which file and terms?

Verify the license attached to the exact official checkpoint repository and any extra conditions in the service's terms.

Do not confuse open weights with an unrestricted OSI-approved open-source license. See SXF's AI Model Licensing for Commercial Use for a deeper method to document license evidence before release. For a production product or redistribution, obtain a formal license review.

How to interpret FLUX 3 Klein benchmarks without copying vendor marketing

Vendor-reported findings: BFL reports that the newer 5.6B model scores ahead of FLUX.2 Klein 9B in its internal comparisons, and quotes RTX generation-speed figures under controlled configurations. Those are valuable vendor-reported data, not independent SXF measurements. Primary methodology and charts.

Independent reports: ComputingForGeeks describes actual low-memory ComfyUI runs and system RAM constraints. Hardware, service routing and prompt settings differ among those reports, so do not combine them into an invented universal “speedup.”

09 / COMMON FAILURES

FLUX 3 Klein installation problems and how to diagnose them

Hugging Face returns 401, 403 or a gated-repository error
Authenticate with the correct account and accept the terms for the exact repository (main model and/or ComfyUI files); then retry. A permission error is unrelated to CUDA.
ComfyUI cannot load the weight format
Update ComfyUI and matching loaders, and verify you downloaded the intended INT8, BF16 or NVFP4 file. NVFP4 requires supported kernels/hardware.
The model fits until you enable prompt enhancement
Account for the separate upsampler, text encoder and offloading plan. Compare the official workflow settings, not file sizes alone.
Image generation is very slow on an 8GB card
Inspect CPU offloading, RAM pressure, SSD throughput, GPU architecture and warmup. Do not compare a 3060 Ti offloading setup with an RTX 5090 vendor timing.
Text in images is inaccurate
Test prompts with short unambiguous text and control for the vendor's prompt-upscaling options. Small text and long passages remain failure cases worth testing.
An image edit unexpectedly changes another region
Check the editing workflow, bounding-box coordinates, strength controls and image resolution; don't promise pixel-perfect protection without the relevant feature enabled.

Checklist before choosing FLUX 3 Klein for a real project

  • Record the exact dated official model release and repository.
  • Identify the Distilled or Base checkpoint and weight precision.

11 / SEARCH QUESTIONS ANSWERED

Frequently asked questions about FLUX 3 Image Klein

Can FLUX 3 Image Klein run on 8GB VRAM?

Black Forest Labs documents an INT8 ComfyUI/Diffusers path on some NVIDIA RTX cards with as little as 8GB VRAM. That is not a universal minimum for the BF16 reference pipeline, especially with prompt upsampling enabled.

Is FLUX 3 Image Klein free or open source?

It is an open-weights model released under the FLUX Kommunity License, not automatically an OSI-approved open-source software license. Commercial rights depend on the precise license terms and user eligibility.

What is the difference between the Base and Distilled checkpoints?

The distilled checkpoint is designed for lower-latency generation; the base checkpoint is intended for fine-tuning and research. They should not be compared at different step counts as if they were the same workflow.

Does FLUX 3 Klein need ComfyUI?

No. The release supports other compatible runtimes such as Diffusers and reference inference code. ComfyUI is one documented path for the 8GB INT8 configuration.

How much does FLUX 3 Image Klein API generation cost?

The October 15, 2026 BFL announcement says prices start at $0.009 for a 1K image. Confirm the current live tier, resolution and contractual terms on the official pricing page.

Can I sell images generated with FLUX 3 Klein?

Usage rights must be evaluated under the actual FLUX Kommunity License and any product or platform terms. BFL states a commercial-use allowance for eligible users under a revenue threshold, but the license text controls.

Should I replace FLUX.2 Klein 9B with FLUX 3 Klein?

Not automatically. Compare the current task, hardware requirements, license, image quality, edits and API billing. FLUX.2 Klein remains a possible lower-cost option for simpler workloads.

Do the 5.6GB INT8 weights mean I need only 5.6GB total VRAM?

No. Model-file size excludes text encoder, autoencoder, intermediate tensors, runtime buffers and prompt-upscaling overhead. Measure peak memory for your exact configuration.
