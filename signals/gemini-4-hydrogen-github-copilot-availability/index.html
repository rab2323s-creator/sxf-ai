SXF VERIFIED BRIEF

GitHub expanded the selectable Copilot model list with Gemini 4 Hydrogen on November 13, 2026, with support in IDEs, web, mobile, CLI, agents and SDK subject to rollout.

QUICK ANSWER

Gemini 4 Hydrogen is available in GitHub Copilot Pro, Pro+, Max, Business and Enterprise, subject to rollout and organization policy. In GitHub's November 2026 Copilot pricing, it costs $1.50 per million input tokens, $0.075 per million cached input tokens and $7.50 per million output tokens. Open Copilot Chat's model picker to select it; this is not a claim that it controls all inline completions.

WHY IT MATTERS

Developers now have a fast-oriented Gemini 4 option in an existing workflow, but plan permissions and cost-per-accepted-task remain more useful than unverified speed claims.

WHAT TO VERIFY

GitHub uses usage-based provider-list billing, so the price is not necessarily a fixed subscription-only inclusion. Gradual rollout and enterprise model policy can prevent a specific account from seeing the model immediately.

SETUP / ACCESS CHECKLIST

How to enable Gemini 4 Hydrogen in VS Code and GitHub Copilot

GitHub's November 13 release lists Copilot Pro, Pro+, Max, Business and Enterprise; clients include VS Code, Visual Studio, JetBrains, Xcode, Eclipse, the CLI, coding agent, GitHub.com, mobile app and SDK. Availability is gradual and depends on the client and administrator settings.

  1. Confirm your plan: Copilot Pro or higher is named in the launch note. Free and Student access is governed by auto model selection and must not be confused with direct model-picker access.
  2. In VS Code: open Copilot Chat, choose the current-model dropdown at the bottom of the chat view, and select Gemini 4 Hydrogen if available. Update VS Code and the Copilot extension if needed.
  3. For Business or Enterprise: ask an organization owner to review Organization Settings → Copilot → Models. An enterprise-enforced restriction cannot be overridden by the organization.
  4. For other clients: check that product's model picker and published support list; different surfaces can roll out at different times.

TECHNICAL ANALYSIS / 02

Gemini 4 Hydrogen vs Gemini 4 Carbon: which should a developer test?

Hydrogen is described as Google's Flash-oriented model for quick agentic coding and instruction following. Carbon is described as the more demanding coding and reasoning option, with a focus on security-oriented work. This is the vendors' product positioning, not measured proof that Hydrogen is cheaper for every accepted pull request or that Carbon always writes safer code.

SXF recommends a paired evaluation: attempt the same documented bug fix, repository question, multistep refactor and security review with both models where the plan permits. Record first useful answer, test-pass rate, manual edits, tool calls and final usage charges. The lower cost per accepted and reviewed change, not the model name, should guide routing.

Example: estimated token cost for the same coding workload

For 500,000 uncached input tokens and 100,000 output tokens with no separate cached input: Hydrogen is $1.50; Carbon's November promotional rate is $2.00; Carbon's published rate from December 1 would be $4.00. Formula: (input tokens ÷ 1,000,000 × input rate) + (output tokens ÷ 1,000,000 × output rate).

This is an illustrative price calculation, not a measured SXF benchmark or a user's invoice. A lower per-token rate also does not prove a lower cost per correct merged pull request.

TECHNICAL ANALYSIS / 03

What does usage-based billing mean in Copilot?

The announcement says Hydrogen uses provider list pricing under usage-based billing. That is not a per-request quote and is not interchangeable with a standalone Gemini API token rate. Copilot subscriptions, enterprise controls and user-specific spend policies determine how the charge appears in the billing system.

Before a team-wide rollout, verify current account pricing and limits, then run a small fixed workload while recording usage and accepted results. Compare model costs on identical tasks and set administrative spending or usage limits where supported, especially if agents can invoke tools repeatedly.

MIGRATION / DECEMBER 14, 2026

Replacing Gemini 3.8 Flash with Hydrogen in Copilot before December 14

GitHub lists December 14, 2026 as the retirement date for Gemini 3.8 Flash across Copilot experiences and names Gemini 4 Hydrogen as the suggested alternative. That makes this a time-bound Copilot migration task, not a declaration that all Gemini API users must migrate.

  1. Inventory: locate team documentation, reusable prompts and workflow configuration that explicitly select Gemini 3.8 Flash.
  2. Check model policy: confirm the enterprise and organization allow Hydrogen before changing team defaults.
  3. Run a paired evaluation: test the same bug fix, repository question, refactor and tool-using agent task on both models where available.
  4. Review accepted results: record tests passed, edits required, reviewer time, tool calls, latency and token cost—not only first-answer speed.
  5. Update and monitor: switch approved workflows, document fallbacks and revisit costs after the December policy and pricing changes.

SXF research note: this is a reproducible evaluation design, not a claim that SXF measured Hydrogen's performance. Use a fixed repository revision, identical prompts and meaningful human review before calling one model superior. See the Gemini 4 model family overview for broader model context, not Copilot-specific plan rules.

READER QUESTIONS

Gemini 4 Hydrogen Copilot: price, access and model selection FAQs

Is Gemini 4 Hydrogen available on Copilot Pro?

Yes, GitHub names Pro alongside Pro+, Max, Business and Enterprise in the November 13 release. Rollout is gradual.

Is Hydrogen the same as Gemini 4 Carbon?

No. They are separate selectable Copilot models with different intended uses and plan eligibility, according to GitHub's two release notes.

Will Gemini 3.8 Flash remain in Copilot?

GitHub announced a December 14, 2026 deprecation and names Gemini 4 Hydrogen as its suggested alternative.

How much does Gemini 4 Hydrogen cost in GitHub Copilot?

As checked November 15, 2026, GitHub lists $1.50 per million input tokens, $0.075 per million cached input tokens, and $7.50 per million output tokens, before plan-specific AI credits, budgets and usage effects. This is Copilot pricing, not Google's standalone Gemini API.

How do I select Gemini 4 Hydrogen in VS Code Copilot Chat?

Open Copilot Chat, use the model dropdown at the bottom of the Chat view and choose Gemini 4 Hydrogen if your plan, client, rollout and administrator policy allow it. Chat selection is separate from inline completion model settings.

Why is Gemini 4 Hydrogen missing from the Copilot model picker?

Check the Copilot subscription, client update, gradual release status and organization or enterprise model policy. GitHub does not promise every account sees a newly launched model immediately.
